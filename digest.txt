# AURA â€” Adaptive Unified Responsive Assistant

A local, working-prototype personal assistant built on Google's
[Live API web console](https://github.com/google-gemini/live-api-web-console).

- **Assistant**: real-time voice conversations with Gemini Live, plus typed messages in the same session.
  It can search the web (Google Search grounding) for news and other current information and shows its sources.
- **Memory**: AURA learns durable facts from your conversations, stores them in SQLite on your computer,
  and recalls them in later sessions (even after a restart). You can inspect, edit, restore and delete them.
- **Meeting Mode**: records a room through your microphone and produces a timestamped transcript with
  speaker labels. People with a registered voice profile appear by name; everyone else becomes
  Speaker 1, Speaker 2, â€¦ You can rename speakers, move or merge lines, fix text, and export.

Everything except the Gemini API calls runs on your machine.

## Requirements

- **Node.js 22.13 or newer** (Node 24 LTS recommended). AURA uses Node's built-in SQLite module, so
  nothing native has to be compiled.
- A Gemini API key from <https://aistudio.google.com/apikey>.
- Chrome or Edge (microphone access requires `localhost` or HTTPS).
- About 70 MB of disk for the local models, downloaded automatically on first start.

## Setup and start

```bash
npm install
cp .env.example .env        # Windows: copy .env.example .env
# open .env and paste your key after GEMINI_API_KEY=
npm run dev
```

`npm run dev` starts the local server on port 3001 and the web app on <http://localhost:3000>.
The first start downloads three small models from the Hugging Face hub into `data/models`
(memory search, voiceprints, speaker-change detection). The Meeting page shows a notice while that is happening.

Single-port alternative: `npm run build` once, then `npm run serve` and open <http://localhost:3001>.

## How it works


### Assistant (`src/hooks/use-live-api.ts`, `src/lib/genai-live-client.ts`)

- Reuses the console's Gemini Live client, audio recorder, audio streamer and worklets.
- The browser never sees the API key: the server issues a single-use
  [ephemeral token](https://ai.google.dev/gemini-api/docs/ephemeral-tokens) for each session.
- Input and output audio transcription are enabled, so spoken turns appear as text and are saved.
- Dropped sessions show a **Reconnect** button that resumes the same context (session resumption);
  server `goAway` notices reconnect automatically. Microphone and API errors are shown in plain words.
- Default Live model: `gemini-3.1-flash-live-preview` (change it in Settings, e.g. to
  `gemini-2.5-flash-native-audio-latest`).
- **Web search**: the session is given Gemini's built-in Google Search tool, so questions about news,
  scores, prices or anything recent are answered from the web. Answers that used search show the
  search terms and numbered source links; the sources are saved with the conversation. Turn it off in
  Settings ("Let AURA search the web"). Search runs inside Gemini; nothing else is called.

### Memory (`server/memory.mjs`)

- **Extraction**: a few seconds after each reply (and when a session ends), new messages are sent to
  Gemini (`GEMINI_TEXT_MODEL`, default `gemini-3.5-flash-lite`, chosen for its larger free daily quota) together with the related existing
  memories. The model returns `add` / `update` / `retire` / `forget` operations.
- **Conflicts**: an `update` never overwrites. The old fact is kept with status *superseded* and a
  link to its replacement; `retire` marks a fact *outdated*. Only *active* facts are given to the
  assistant, each with its "last confirmed" date. The model can only change memories it was shown.
- **Retrieval**: sentence embeddings from a local model (`Xenova/all-MiniLM-L6-v2` via transformers.js)
  plus keyword overlap. The 30 most recent active facts are placed in the Live system prompt; the
  assistant can search the rest through a `recall_memories` tool, and typed messages get the closest
  matches attached. If the embedding model can't load, search falls back to keywords.
- **Asking before changes**: new facts are saved automatically, but when AURA wants to change, mark
  outdated or delete a memory you already have, it asks first (a card in the Assistant view and on the
  Memory page, with a badge in the sidebar). You can accept, edit the wording first, or keep the old
  fact; a change you turned down isn't proposed again. Turn this off in Settings.
- **Conversations** are stored and listed in the sidebar (pinned ones first). Open one to read it,
  **continue it** (the assistant gets the earlier messages as context), rename it (click the title),
  pin it, export it as Markdown, text or JSON, or delete it.

### Meeting Mode (`src/lib/segmenter.ts`, `server/meetings.mjs`)

1. The browser records 16 kHz audio and cuts it into pieces at pauses (energy-based voice
   activity detection; â‰¥0.7 s silence, max 10 s per piece).
2. **Speaker changes inside a piece** are found with a local speaker-segmentation model
   (`onnx-community/pyannote-segmentation-3.0`), so two people talking back to back become two lines.
   Very short turns (< 0.6 s) are folded into their neighbour.
3. Each turn gets a **voiceprint** from a local model (`onnx-community/wespeaker-voxceleb-resnet34-LM`,
   the embedding model behind pyannote 3.x).
4. The voiceprint is compared with the voices already heard in this meeting (default similarity
   â‰¥ 0.55) and with registered voice profiles (â‰¥ 0.58, and clearly ahead of the next profile).
   Otherwise it becomes a new *Speaker N*. Numbers are never reused within a meeting. An unnamed
   speaker who later turns out to match a profile gets that name.
5. Turns are **transcribed by Gemini**, in one of two ways (Settings â†’ Meeting Mode â†’ Transcription):
   - **Live** (default): the browser keeps a Live API session open with `gemini-3.5-transcribe-live`
     and sends each speaker turn as its own utterance. On the free tier this model has no daily request
     cap. If it fails, the rest of the meeting switches to Standard automatically, and turns the
     browser never reported back are transcribed by the server.
   - **Standard**: turns are collected for a few seconds and sent several at a time to
     `GEMINI_TRANSCRIBE_MODEL` (default `gemini-3.5-flash-lite`), together with the last few transcript
     lines as context. An optional language hint (Settings, e.g. "English and Hindi") helps with mixed-language
   meetings. 429/5xx responses are retried; failed or empty pieces keep their audio and can be retried.
6. **After the meeting ends**, every line is checked again against the final voiceprint of each
   speaker: unnamed speakers that are really one person are merged, and lines that clearly belong to
   someone else are moved. Lines you moved by hand and speakers you renamed are never changed.
5. Corrections: click a speaker chip to rename it everywhere, use the merge icon when one person was
   split in two (their future lines follow the merge), change a single line's speaker from its
   dropdown, double-click text to fix it. Export as text, Markdown or JSON.

Voice profiles (Meeting Mode â†’ Voice profiles) require ticking a consent box and reading a short
passage for at least 12 seconds. Record them with the microphone and room you use for meetings.
Only the numeric voiceprint is stored, not the recording. "Test recognition" shows the similarity to
every profile for a fresh sample, which helps tune the thresholds in Settings. Profiles made with an
older speaker model are marked and must be re-recorded (voiceprints from different models can't be
compared).

## Your data

All data lives in `data/` (git-ignored): `aura.db` (conversations, memories, meetings, voice
profiles) and `models/` (downloaded model files). Delete items individually in the app, or use
Settings â†’ Your data to delete conversations, memories, transcripts or everything.

## Tests

```bash
npm run test:server   # API, memory conflict handling, speaker attribution, corrections, export
npm test -- --watchAll=false   # frontend unit tests (voice-activity segmenter)
```

The server tests replace Gemini and the two local models with fakes, so they check AURA's own logic,
not model quality.

## Known limitations (honest status)

- **Speaker recognition accuracy has not been measured on real meetings.** The models and thresholds
  were checked only on synthetic voices with added room noise and echo: there, the same voice scored
  0.61â€“0.96 and different voices âˆ’0.02â€“0.56, and a 12-line test meeting with two registered and two
  unregistered voices (including two people talking back to back) was attributed correctly. Real
  rooms will do worse. Expect mistakes with similar voices, people far from the microphone,
  short interjections (under 1 s they are attached to the previous speaker and marked *unsure*) and
  overlapping speech (overlaps go to whoever was already talking). Lines near a threshold are marked
  *unsure*; correct them in the transcript.
- One laptop microphone in a room is the hardest case for any speaker recognition. Recording voice
  profiles in the same room and on the same microphone helps the most.
- Transcription quality and speed depend on the Gemini model and your API quota. Standard
  transcription uses the daily request quota of the text model; Live transcription doesn't, but a Live
  session lasts at most 10 minutes and is reopened automatically.
- Web search on the free tier: Google's quota table lists Search grounding for Gemini 3 models at 0
  requests/day on free keys. If answers that need the web fail or come back without sources, switch the
  Live model in Settings to `gemini-2.5-flash-native-audio-preview-12-2025` (Gemini 2.5 grounding quota).
- Memory extraction depends on Gemini's judgment; review the Memory page and correct anything wrong.
- Only one microphone user at a time: starting a meeting ends the current voice session.
- Single local user, no accounts. The server listens on 127.0.0.1 only.

// Small helpers for 16 kHz mono PCM16 audio.
export const SAMPLE_RATE = 16000;

export function pcmToWav(pcm, sampleRate = SAMPLE_RATE) {
  const header = Buffer.alloc(44);
  header.write("RIFF", 0);
  header.writeUInt32LE(36 + pcm.length, 4);
  header.write("WAVE", 8);
  header.write("fmt ", 12);
  header.writeUInt32LE(16, 16);
  header.writeUInt16LE(1, 20); // PCM
  header.writeUInt16LE(1, 22); // mono
  header.writeUInt32LE(sampleRate, 24);
  header.writeUInt32LE(sampleRate * 2, 28);
  header.writeUInt16LE(2, 32);
  header.writeUInt16LE(16, 34);
  header.write("data", 36);
  header.writeUInt32LE(pcm.length, 40);
  return Buffer.concat([header, pcm]);
}

/** PCM16 little-endian buffer -> Float32Array in [-1, 1]. */
export function pcmToFloat32(pcm) {
  const n = Math.floor(pcm.length / 2);
  const out = new Float32Array(n);
  for (let i = 0; i < n; i++) out[i] = pcm.readInt16LE(i * 2) / 32768;
  return out;
}

export const pcmSeconds = (pcm) => pcm.length / 2 / SAMPLE_RATE;

export function getConversation(id) {
  const c = db.prepare("SELECT * FROM conversations WHERE id = ?").get(id);
  if (!c) return null;
  const messages = db
    .prepare("SELECT id, role, modality, text, meta, created_at FROM messages WHERE conversation_id = ? ORDER BY id")
    .all(id)
    .map((m) => ({ id: m.id, role: m.role, modality: m.modality, text: m.text, createdAt: m.created_at, ...parseMeta(m.meta) }));
  const firstUser = messages.find((m) => m.role === "user")?.text;
  return {
    id: c.id,
    title: c.title || (firstUser ? firstUser.slice(0, 60) : "Conversation"),
    renamed: !!c.title,
    pinned: !!c.pinned,
    startedAt: c.started_at,
    updatedAt: c.updated_at,
    messages,
  };
}

function parseMeta(meta) {
  if (!meta) return {};
  try {
    return JSON.parse(meta);

    return {};
  }
}

/** Keep only the web-search details we show: source links and the queries used. */
export function cleanSearchMeta(input) {
  if (!input || typeof input !== "object") return null;
  const sources = Array.isArray(input.sources)
    ? input.sources
        .filter((s) => s && /^https?:\/\//.test(String(s.uri || "")))
        .slice(0, 12)
        .map((s) => ({ title: String(s.title || s.uri).slice(0, 200), uri: String(s.uri).slice(0, 2000) }))
    : [];
  const searchQueries = Array.isArray(input.searchQueries) ? input.searchQueries.slice(0, 8).map((q) => String(q).slice(0, 300)) : [];
  if (!sources.length && !searchQueries.length) return null;
  return { sources, searchQueries };
}

export function historyForPrompt(id, maxChars = 8000) {
  const rows = db.prepare("SELECT role, text FROM messages WHERE conversation_id = ? ORDER BY id DESC LIMIT 60").all(id);
  const lines = [];

}

export function exportConversation(id, format) {
  const c = getConversation(id);
  if (!c) return null;
  const who = (m) => (m.role === "user" ? "You" : "AURA");
  const when = (t) => new Date(t).toLocaleString();
  if (format === "json") {
    return {
      mime: "application/json",
      ext: "json",
      title: c.title,
      body: JSON.stringify(
        {
          title: c.title,
          startedAt: new Date(c.startedAt).toISOString(),
          messages: c.messages.map((m) => ({
            role: m.role,
            modality: m.modality,
            text: m.text,
            at: new Date(m.createdAt).toISOString(),
            ...(m.sources ? { sources: m.sources } : {}),
          })),
        },
        null,
        2
      ),
    };
  }
  if (format === "md") {
    const body = [
      `# ${c.title}`,
      "",
      `_${when(c.startedAt)}_`,
      "",
      ...c.messages.map((m) => {
        const src = m.sources?.length ? "\n\n" + m.sources.map((s, i) => `${i + 1}. [${s.title}](${s.uri})`).join("\n") : "";
        return `**${who(m)}**: ${m.text}${src}\n`;
      }),
    ].join("\n");
    return { mime: "text/markdown", ext: "md", title: c.title, body };
  }
  const body = [c.title, when(c.startedAt), "", ...c.messages.map((m) => `[${new Date(m.createdAt).toLocaleTimeString()}] ${who(m)}: ${m.text}`)].join("\n");
  return { mime: "text/plain", ext: "txt", title: c.title, body };
}

/** Short-lived, single-use token the browser uses to open a Gemini Live session. */
export async function createLiveToken() {
  await client(); // throws a helpful error when the key is missing
  const { GoogleGenAI } = await genai();
  const c = new GoogleGenAI({ apiKey: GEMINI_API_KEY, httpOptions: { apiVersion: "v1alpha" } });
  const t = Date.now();
  const token = await c.authTokens.create({
    config: {
      uses: 1,
      // the session itself may last up to 3 hours, a new one must start within 2 minutes
      expireTime: new Date(t + 3 * 60 * 60 * 1000).toISOString(),
      newSessionExpireTime: new Date(t + 2 * 60 * 1000).toISOString(),
      httpOptions: { apiVersion: "v1alpha" },
    },
  });
  return { token: token.name, expiresAt: t + 2 * 60 * 1000 };
}

const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

function isRetryable(e) {
  const s = e?.status ?? e?.code;
  return s === 429 || s === 500 || s === 503 || s === 504 || /fetch failed|ECONNRESET|ETIMEDOUT/i.test(String(e?.message));
}

async function withRetry(fn, tries = 4) {
  let delay = 2000;
  for (let i = 0; ; i++) {
    try {
      return await fn();
    } catch (e) {
      if (i >= tries - 1 || !isRetryable(e)) throw e;
      // honour "retry in Xs" hints from 429 responses when present
      const m = /retry in ([\d.]+)s/i.exec(String(e?.message));
      await sleep(m ? Math.min(60000, Number(m[1]) * 1000 + 250) : delay);
      delay *= 2;
    }
  }
}

/** Generate JSON that follows `schema` (a JSON Schema object). */
export async function generateJSON({ system, prompt, schema, model = TEXT_MODEL, parts }) {
  const c = await client();
  const res = await withRetry(() =>
    c.models.generateContent({
      model,
      contents: [{ role: "user", parts: parts || [{ text: prompt }] }],
      config: {
        systemInstruction: system,
        responseMimeType: "application/json",
        responseJsonSchema: schema,
        temperature: 0.1,
      },
    })
  );
  const text = res.text || "";
  try {
    return JSON.parse(text);
  } catch {
    const m = text.match(/[[{][\s\S]*[\]}]/);
    if (m) return JSON.parse(m[0]);
    throw new Error("Model did not return valid JSON");
  }
}

/**
 * Transcribe several short PCM16 (16 kHz mono) clips in one request.
 * `context` is the most recent transcript (plain text) to help with names and terms.
 * Returns { texts, raw }: one string per clip, in order ("" when no intelligible speech).
 */
export async function transcribeSegments(pcmBuffers, { context = "", language = "" } = {}) {
  const n = pcmBuffers.length;
  const parts = [];
  if (context) {
    parts.push({ text: `Transcript so far (for context only, do not repeat it):\n${context}` });
  }
  pcmBuffers.forEach((pcm, i) => {
    parts.push({ text: `Clip ${i + 1} of ${n}:` });
    parts.push({ inlineData: { mimeType: "audio/wav", data: pcmToWav(pcm).toString("base64") } });
  });
  parts.push({
    text:
      `Transcribe each of the ${n} audio clips above, word for word. ` +
      `Return "transcripts" as an array of exactly ${n} strings: the first string is clip 1, the second is clip 2, and so on. ` +
      (language
        ? `The speakers mostly use: ${language}. `
        : `Write each clip in the language it is spoken in. `) +
      `If speakers mix languages (for example Hindi and English), keep the words as spoken; do not translate. ` +
      `Use normal punctuation. Leave out filler sounds like "um". ` +
      `Use an empty string only when a clip has no intelligible speech at all. ` +
      `Do not add speaker names, timestamps, descriptions or comments.`,
  });
  const out = await generateJSON({
    model: TRANSCRIBE_MODEL,
    system: "You are an accurate meeting transcriber. You only write down what is said in the audio.",
    parts,
    schema: {
      type: "object",
      properties: {
        transcripts: { type: "array", items: { type: "string" }, minItems: n, maxItems: n },
      },
      required: ["transcripts"],
    },
  });
  const list = Array.isArray(out?.transcripts) ? out.transcripts : Array.isArray(out) ? out : [];
  const texts = new Array(n).fill("");
  for (let i = 0; i < n && i < list.length; i++) {
    const v = list[i];
    texts[i] = String(typeof v === "string" ? v : v?.text ?? "").trim();
  }
  return { texts, raw: out, count: list.length };
}

const MAX_BODY = 50 * 1024 * 1024;
function readBody(req) {
  return new Promise((resolve, reject) => {
    const chunks = [];
    let size = 0;
    req.on("data", (c) => {
      size += c.length;
      if (size > MAX_BODY) {
        reject(Object.assign(new Error("Request too large"), { status: 413 }));
        req.destroy();
      } else chunks.push(c);
    });
    req.on("end", () => resolve(Buffer.concat(chunks)));
    req.on("error", reject);
  });
}

function sendJSON(res, status, data) {
  const body = JSON.stringify(data ?? { ok: true });
  res.writeHead(status, { "Content-Type": "application/json; charset=utf-8", "Cache-Control": "no-store" });
  res.end(body);
}

const BUILD = path.join(ROOT_DIR, "build");
const MIME = { ".html": "text/html", ".js": "text/javascript", ".css": "text/css", ".json": "application/json", ".ico": "image/x-icon", ".png": "image/png", ".svg": "image/svg+xml", ".txt": "text/plain", ".map": "application/json" };
function serveStatic(req, res, pathname) {
  if (!fs.existsSync(path.join(BUILD, "index.html"))) return false;
  let file = path.normalize(path.join(BUILD, decodeURIComponent(pathname)));
  if (!file.startsWith(BUILD) || !fs.existsSync(file) || fs.statSync(file).isDirectory()) file = path.join(BUILD, "index.html");
  res.writeHead(200, { "Content-Type": MIME[path.extname(file)] || "application/octet-stream" });
  fs.createReadStream(file).pipe(res);
  return true;
}

// ---- server ------------------------------------------------------------------------------------------
const server = http.createServer(async (req, res) => {
  const url = new URL(req.url, "http://localhost");
  req.query = Object.fromEntries(url.searchParams);
  try {
    if (!url.pathname.startsWith("/api/")) {
      if (req.method === "GET" && serveStatic(req, res, url.pathname)) return;
      throw notFound();
    }
    let route = null;
    for (const r of routes) {
      if (r.method !== req.method) continue;
      const m = r.re.exec(url.pathname);
      if (m) {
        route = r;
        req.params = Object.fromEntries(r.keys.map((k, i) => [k, decodeURIComponent(m[i + 1])]));
        break;
      }
    }
    if (!route) throw Object.assign(new Error("Unknown endpoint"), { status: 404 });
    const body = await readBody(req);
    if (route.raw) req.body = body;
    else if (body.length) {
      try {
        req.body = JSON.parse(body.toString("utf8"));
      } catch {
        throw bad("Invalid JSON body");
      }
    } else req.body = {};
    const out = await route.handler(req, res);
    if (!res.headersSent) sendJSON(res, 200, out);
  } catch (e) {
    if (!e.status || e.status >= 500) console.error(`[api] ${req.method} ${url.pathname}:`, e.message);
    if (!res.headersSent) sendJSON(res, e.status || 500, { error: e.message || "Server error" });
  }
});

export function start(port = PORT) {
  return new Promise((resolve) => {
    server.listen(port, "127.0.0.1", () => {
      console.log(`[aura] server on http://localhost:${port}  (data: ${DATA_DIR})`);
      if (!hasKey()) console.warn("[aura] GEMINI_API_KEY is missing - add it to .env (see README).");

      meet.resumePending();
      if (process.env.AURA_NO_WARMUP !== "1") warmUp();
      resolve(server);
    });
  });
}

// Meeting Mode: speaker-attributed transcription.
//
// Pipeline per piece of speech (cut at pauses by the browser):
//   1. speaker-change detection inside the piece (pyannote segmentation, local)
//      -> the piece is split into one turn per speaker
//   2. a voiceprint per turn (WeSpeaker ResNet34, local)
//   3. match against voices already heard in this meeting and registered voice
//      profiles -> registered name, the same "Speaker N" as before, or a new one
//   4. transcription with the Gemini API, several turns per request
//   5. when the meeting ends, a refinement pass re-checks every line against the
//      final picture of each voice (early decisions are made with little data)

/** Profiles whose voiceprint was made by the current speaker model. */
function currentProfiles() {
  return db
    .prepare("SELECT id, name, embedding FROM speaker_profiles WHERE model = ?")
    .all(SPEAKER_MODEL)
    .map((p) => ({ id: p.id, name: p.name, emb: blobToF32(p.embedding) }));

export async function enrollProfile({ name, pcm, consentNote, replaceId }) {
  const secs = pcmSeconds(pcm);
  if (secs < 8) throw Object.assign(new Error("Need at least 8 seconds of speech to enroll a voice."), { status: 400 });
  const emb = await embedSpeaker(pcmToFloat32(pcm));
  if (replaceId) {
    const n = db
      .prepare("UPDATE speaker_profiles SET name = ?, embedding = ?, sample_seconds = ?, consent_note = ?, created_at = ?, model = ? WHERE id = ?")
      .run(name.trim(), f32ToBlob(emb), secs, consentNote, now(), SPEAKER_MODEL, replaceId).changes;
    if (n) return listProfiles().find((p) => p.id === Number(replaceId));
  }
  const info = db
    .prepare("INSERT INTO speaker_profiles(name, embedding, sample_seconds, consent_note, created_at, model) VALUES (?, ?, ?, ?, ?, ?)")
    .run(name.trim(), f32ToBlob(emb), secs, consentNote, now(), SPEAKER_MODEL);
  return listProfiles().find((p) => p.id === Number(info.lastInsertRowid));
}

/** Score a recording against the registered profiles (used by the "test recognition" check). */
export async function identify(pcm) {
  const emb = await embedSpeaker(pcmToFloat32(pcm));
  return currentProfiles()
    .map((p) => ({ id: p.id, name: p.name, score: cosine(emb, p.emb) }))
    .sort((a, b) => b.score - a.score);
}

export function getMeeting(id) {
  const m = db.prepare("SELECT * FROM meetings WHERE id = ?").get(id);
  if (!m) return null;
  const speakers = db
    .prepare("SELECT id, label, profile_id, match_score, renamed, n FROM meeting_speakers WHERE meeting_id = ? AND merged_into IS NULL ORDER BY id")
    .all(id)
    .map((s) => ({ id: s.id, label: s.label, profileId: s.profile_id, matchScore: s.match_score, renamed: !!s.renamed, segments: s.n }));
  const segments = db
    .prepare(
      `SELECT id, speaker_id, start_ms, end_ms, text, speaker_score, speaker_uncertain, status, error, manual,
              (audio IS NOT NULL) AS has_audio
       FROM segments WHERE meeting_id = ? ORDER BY start_ms`
    )
    .all(id)
    .map((s) => ({
      id: s.id,
      speakerId: s.speaker_id,
      startMs: s.start_ms,
      endMs: s.end_ms,
      text: s.text,
      speakerScore: s.speaker_score,
      speakerUncertain: !!s.speaker_uncertain,
      status: s.status,
      error: s.error,
      retryable: (s.status === "error" || s.status === "empty") && !!s.has_audio,
    }));
  return { id: m.id, title: m.title, startedAt: m.started_at, endedAt: m.ended_at, refined: !!m.refined, speakers, segments };
}

/**
 * Live-transcription mode: analyse the piece right away and return its speaker
 * turns; the browser transcribes each turn over the Live API and posts the text back.
 */
export async function addSegmentLive(meetingId, { startMs, endMs, pcm }) {
  const id = Number(
    db
      .prepare("INSERT INTO segments(meeting_id, start_ms, end_ms, status, audio) VALUES (?, ?, ?, 'analysing', ?)")
      .run(meetingId, Math.round(startMs), Math.round(endMs), pcm).lastInsertRowid
  );
  const seg = db.prepare("SELECT id, meeting_id, start_ms, end_ms, audio FROM segments WHERE id = ?").get(id);
  let ids;
  try {
    ids = await analysePiece(seg, getSettings(), "live");
  } catch (e) {
    console.error("[meeting] speaker analysis failed:", e.message);
    workerState.lastError = `Speaker model: ${e.message}`;
    workerState.lastErrorAt = now();
    db.prepare("UPDATE segments SET status = 'live' WHERE id = ?").run(id);
    liveSince.set(id, Date.now());
    ids = [id];
  }
  return db
    .prepare(`SELECT id, start_ms, end_ms FROM segments WHERE id IN (${ids.map(() => "?").join(",")}) ORDER BY start_ms`)
    .all(...ids)
    .map((r) => ({ id: r.id, startMs: r.start_ms, endMs: r.end_ms }));
}

/** Text for a turn transcribed in the browser. `failed` hands it to the standard transcription instead. */
export function setLiveTranscript(meetingId, segmentId, { text, failed }) {
  const seg = db.prepare("SELECT status FROM segments WHERE id = ? AND meeting_id = ?").get(segmentId, meetingId);
  if (!seg || seg.status !== "live") return false;
  liveSince.delete(segmentId);
  if (failed) {
    db.prepare("UPDATE segments SET status = 'queued' WHERE id = ?").run(segmentId);
    queuedAt.set(segmentId, 0);
    kick();
  } else if (String(text || "").trim()) {
    db.prepare("UPDATE segments SET text = ?, status = 'done', error = NULL, audio = NULL WHERE id = ?").run(String(text).trim(), segmentId);
  } else {
    db.prepare("UPDATE segments SET text = '', status = 'empty' WHERE id = ?").run(segmentId);
  }
  kick(); // may complete the meeting -> refinement
  return true;
}

/** Move one segment to another (or a new) speaker. */
export function reassignSegment(meetingId, segmentId, { speakerId, newLabel }) {
  let target = speakerId;
  if (!target && newLabel) {
    target = Number(
      db.prepare("INSERT INTO meeting_speakers(meeting_id, label, renamed, n) VALUES (?, ?, 1, 0)").run(meetingId, newLabel.trim())
        .lastInsertRowid
    );
  }
  const seg = db.prepare("SELECT speaker_id FROM segments WHERE id = ? AND meeting_id = ?").get(segmentId, meetingId);
  if (!seg) return;
  db.prepare("UPDATE segments SET speaker_id = ?, speaker_uncertain = 0, manual = 1 WHERE id = ?").run(target, segmentId);
  db.prepare("UPDATE meeting_speakers SET n = n - 1 WHERE id = ?").run(seg.speaker_id);
  db.prepare("UPDATE meeting_speakers SET n = n + 1 WHERE id = ?").run(target);
}

/** Merge speaker `fromId` into `intoId` (e.g. one person was split into two labels). */
export function mergeSpeakers(meetingId, fromId, intoId) {
  db.transaction(() => {
    const moved = db.prepare("UPDATE segments SET speaker_id = ? WHERE speaker_id = ? AND meeting_id = ?").run(intoId, fromId, meetingId).changes;
    db.prepare("UPDATE meeting_speakers SET n = n + ? WHERE id = ?").run(moved, intoId);
    // keep the voice's centroid so its future lines land on the merged speaker
    db.prepare("UPDATE meeting_speakers SET merged_into = ?, n = 0 WHERE id = ? AND meeting_id = ?").run(intoId, fromId, meetingId);
    db.prepare("UPDATE meeting_speakers SET merged_into = ? WHERE merged_into = ? AND meeting_id = ?").run(intoId, fromId, meetingId);
  })();
}

}

const clock = (ms) => {
  const s = Math.floor(ms / 1000);
  const h = Math.floor(s / 3600);
  const mm = String(Math.floor((s % 3600) / 60)).padStart(2, "0");
  const ss = String(s % 60).padStart(2, "0");
  return h ? `${h}:${mm}:${ss}` : `${mm}:${ss}`;
};

export function exportMeeting(id, format) {
  const m = getMeeting(id);
  if (!m) return null;
  const name = new Map(m.speakers.map((s) => [s.id, s.label]));
  const rows = m.segments
    .filter((s) => s.text)
    .map((s) => ({ start: clock(s.startMs), end: clock(s.endMs), speaker: name.get(s.speakerId) || "Unknown", text: s.text }));
  const date = new Date(m.startedAt).toLocaleString();
  if (format === "json") {
    return { mime: "application/json", ext: "json", body: JSON.stringify({ title: m.title, startedAt: new Date(m.startedAt).toISOString(), segments: rows }, null, 2) };
  }
  if (format === "md") {
    const body = [`# ${m.title}`, ``, `_${date}_`, ``, ...rows.map((r) => `**${r.speaker}** \`[${r.start}]\`  \n${r.text}\n`)].join("\n");
    return { mime: "text/markdown", ext: "md", body };
  }
  const body = [m.title, date, "", ...rows.map((r) => `[${r.start} - ${r.end}] ${r.speaker}: ${r.text}`)].join("\n");
  return { mime: "text/plain", ext: "txt", body };
}

function kick(delay = 0) {
  if (timer) {
    clearTimeout(timer);
    timer = null;
  }
  const go = () => {
    if (running) return;
    running = true;
    work()
      .catch((e) => console.error("[meeting] worker crashed:", e))
      .finally(() => {
        running = false;
        // new pieces may have arrived while finishing
        if (db.prepare("SELECT 1 FROM segments WHERE status = 'pending' LIMIT 1").get()) kick();
      });
  };
  if (delay) timer = setTimeout(go, delay);
  else setImmediate(go);
}

/**
 * Decide who is speaking, given a voiceprint.
 * Compares with every voice already heard in this meeting (and, for named voices,
 * their registered profile) and with registered profiles not heard yet.
 */
function assignSpeaker(meetingId, emb, settings) {
  const profiles = currentProfiles();
  const profileById = new Map(profiles.map((p) => [p.id, p]));
  // includes voices the user merged into someone else: their lines keep going to the merged speaker
  const speakers = db.prepare("SELECT * FROM meeting_speakers WHERE meeting_id = ? AND centroid IS NOT NULL").all(meetingId);

  // 1) voices already in this meeting
  let best = null;
  for (const sp of speakers) {
    let score = cosine(emb, blobToF32(sp.centroid));
    const prof = sp.profile_id && profileById.get(sp.profile_id);
    if (prof) score = Math.max(score, cosine(emb, prof.emb));
    if (!best || score > best.score) best = { sp, score };
  }

  // 2) registered voices not heard yet in this meeting
  const used = new Set(speakers.map((s) => s.profile_id).filter(Boolean));
  const ranked = profiles.map((p) => ({ p, score: cosine(emb, p.emb) })).sort((a, b) => b.score - a.score);
  const top = ranked[0];
  const runnerUp = ranked[1]?.score ?? -1;
  const profileHit =
    top && !used.has(top.p.id) && top.score >= settings.voiceMatchThreshold && top.score - runnerUp >= PROFILE_MARGIN
      ? top
      : null;

  if (best && best.score >= settings.voiceClusterThreshold && (!profileHit || best.score >= profileHit.score)) {
    updateCentroid(best.sp, emb);
    return { speakerId: live(best.sp).id, score: best.score, uncertain: best.score < settings.voiceClusterThreshold + UNSURE_BAND };
  }
  if (profileHit) {
    const id = Number(
      db
        .prepare("INSERT INTO meeting_speakers(meeting_id, label, profile_id, match_score, centroid, n) VALUES (?, ?, ?, ?, ?, 0)")
        .run(meetingId, profileHit.p.name, profileHit.p.id, profileHit.score, f32ToBlob(emb)).lastInsertRowid
    );
    return { speakerId: id, score: profileHit.score, uncertain: profileHit.score < settings.voiceMatchThreshold + UNSURE_BAND };
  }

  // 3) a new voice; numbers are never reused within a meeting, even after renames or merges
  db.prepare("UPDATE meetings SET speaker_seq = speaker_seq + 1 WHERE id = ?").run(meetingId);
  const n = db.prepare("SELECT speaker_seq FROM meetings WHERE id = ?").get(meetingId).speaker_seq;
  const id = db
    .prepare("INSERT INTO meeting_speakers(meeting_id, label, centroid, n) VALUES (?, ?, ?, 0)")
    .run(meetingId, `Speaker ${n}`, f32ToBlob(emb)).lastInsertRowid;
  return { speakerId: Number(id), score: best?.score ?? null, uncertain: false };
}

function updateCentroid(sp, emb) {
  const c = blobToF32(sp.centroid);
  const n = Math.min(sp.n || 0, 30); // cap so the centroid can still adapt
  let next = emb;
  if (c && c.length === emb.length) {
    next = new Float32Array(emb.length);
    for (let i = 0; i < emb.length; i++) next[i] = (c[i] * n + emb[i]) / (n + 1);
    next = normalize(next);
  }
  db.prepare("UPDATE meeting_speakers SET centroid = ? WHERE id = ?").run(f32ToBlob(next), sp.id);
}

/** An unnamed voice that turns out to match a registered profile gets that name. */
function maybeNameSpeaker(speakerId, settings) {
  const sp = speakerRow(speakerId);
  if (!sp || sp.profile_id || sp.renamed || sp.n < 3) return;
  const ranked = currentProfiles()
    .map((p) => ({ p, score: cosine(blobToF32(sp.centroid), p.emb) }))
    .sort((a, b) => b.score - a.score);
  const top = ranked[0];
  if (!top || top.score < settings.voiceMatchThreshold || top.score - (ranked[1]?.score ?? -1) < PROFILE_MARGIN) return;
  const taken = db.prepare("SELECT 1 FROM meeting_speakers WHERE meeting_id = ? AND profile_id = ? AND merged_into IS NULL").get(sp.meeting_id, top.p.id);
  if (taken) return;
  db.prepare("UPDATE meeting_speakers SET label = ?, profile_id = ?, match_score = ? WHERE id = ?").run(top.p.name, top.p.id, top.score, sp.id);
}

/** Step 1-3 for one uploaded piece: split by speaker, voiceprint, attribute. */
async function analysePiece(seg, settings, nextStatus = "queued") {
  const audio = asBuffer(seg.audio);
  const samples = pcmToFloat32(audio);
  const secs = samples.length / SAMPLE_RATE;

  // speaker changes inside the piece
  let turns = [{ start: 0, end: secs, local: 0 }];
  if (secs >= MIN_SPLIT_SECONDS) {
    try {
      turns = await speakerTurns(samples);
    } catch (e) {
      console.error("[meeting] speaker-change detection failed:", e.message);
    }
  }

  // one voiceprint per local speaker, from all of their audio in this piece
  const locals = [...new Set(turns.map((t) => t.local))];
  const decision = new Map();
  for (const l of locals) {
    const mine = turns.filter((t) => t.local === l);
    const total = mine.reduce((a, t) => a + (t.end - t.start), 0);
    if (total < MIN_EMBED_SECONDS) continue;
    const joined = new Float32Array(Math.round(total * SAMPLE_RATE) + mine.length);
    let off = 0;
    for (const t of mine) {
      const part = samples.subarray(Math.round(t.start * SAMPLE_RATE), Math.round(t.end * SAMPLE_RATE));
      joined.set(part, off);
      off += part.length;
    }
    const emb = await embedSpeaker(joined.subarray(0, off));
    decision.set(l, { emb, ...assignSpeaker(seg.meeting_id, emb, settings) });
  }

  // turns without their own decision (too short) join the neighbouring turn
  let pieces = turns.map((t) => ({ ...t, d: decision.get(t.local) || null }));
  if (!pieces.some((p) => p.d)) {
    pieces = [{ start: 0, end: secs, d: null }];
  } else {
    for (let i = 0; i < pieces.length; i++) {
      if (!pieces[i].d) pieces[i].d = (pieces[i - 1] || pieces[i + 1]).d || pieces.find((p) => p.d).d;
    }
  }
  // adjacent turns that ended up with the same speaker become one line again
  const merged = [];
  for (const p of pieces) {
    const last = merged[merged.length - 1];
    if (last && last.d && p.d && last.d.speakerId === p.d.speakerId) last.end = p.end;
    else merged.push({ ...p });
  }

  const prevSpeaker = () =>
    db
      .prepare("SELECT speaker_id FROM segments WHERE meeting_id = ? AND start_ms < ? AND speaker_id IS NOT NULL ORDER BY start_ms DESC LIMIT 1")
      .get(seg.meeting_id, seg.start_ms)?.speaker_id ?? null;

  const ins = db.prepare(
    `INSERT INTO segments(meeting_id, speaker_id, start_ms, end_ms, speaker_score, speaker_uncertain, status, audio, embedding)
     VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)`
  );
  const upd = db.prepare(
    `UPDATE segments SET speaker_id = ?, start_ms = ?, end_ms = ?, speaker_score = ?, speaker_uncertain = ?, status = ?, audio = ?, embedding = ?
     WHERE id = ?`
  );
  const ready = [];
  db.transaction(() => {
    merged.forEach((p, i) => {
      const a = audio.subarray(Math.round(p.start * SAMPLE_RATE) * 2, Math.round(p.end * SAMPLE_RATE) * 2);
      const startMs = Math.round(seg.start_ms + p.start * 1000);
      const endMs = Math.round(seg.start_ms + p.end * 1000);
      // too short for a voiceprint: attach to the previous speaker, flagged as unsure
      const speakerId = p.d ? p.d.speakerId : prevSpeaker();
      const score = p.d ? p.d.score : null;
      const unsure = p.d ? (p.d.uncertain ? 1 : 0) : 1;
      const emb = p.d ? f32ToBlob(p.d.emb) : null;
      let segId = seg.id;
      if (i === 0) upd.run(speakerId, startMs, endMs, score, unsure, nextStatus, Buffer.from(a), emb, seg.id);
      else segId = Number(ins.run(seg.meeting_id, speakerId, startMs, endMs, score, unsure, nextStatus, Buffer.from(a), emb).lastInsertRowid);
      if (speakerId) db.prepare("UPDATE meeting_speakers SET n = n + 1 WHERE id = ?").run(speakerId);
      ready.push(segId);
    });
  })();
  for (const id of ready) (nextStatus === "live" ? liveSince : queuedAt).set(id, Date.now());
  for (const d of decision.values()) maybeNameSpeaker(d.speakerId, settings);
  return ready;
}

/** Recent transcript lines, to give the transcriber context. */
function transcriptContext(meetingId, beforeMs) {
  return db
    .prepare(
      `SELECT s.text, COALESCE(sp.label, 'Unknown') AS label FROM segments s
       LEFT JOIN meeting_speakers sp ON sp.id = s.speaker_id
       WHERE s.meeting_id = ? AND s.status = 'done' AND s.start_ms < ? ORDER BY s.start_ms DESC LIMIT 6`
    )
    .all(meetingId, beforeMs)
    .reverse()
    .map((r) => `${r.label}: ${r.text}`)
    .join("\n");
}

async function transcribeBatch(batch, settings) {
  const meetingId = batch[0].meeting_id;
  const context = transcriptContext(meetingId, batch[0].start_ms);
  const audios = batch.map((b) => asBuffer(b.audio));
  const { texts, raw, count } = await transcribeSegments(audios, { context, language: settings.meetingLanguage });
  if (count !== batch.length) {
    console.warn(`[meeting] transcriber returned ${count} texts for ${batch.length} clips`);
  }
  if (texts.every((t) => !t)) {
    console.warn("[meeting] transcriber returned no text for", batch.length, "clip(s). Raw reply:", JSON.stringify(raw).slice(0, 500));
  }
  // keep the audio of empty clips so "Retry" can try them again
  const done = db.prepare("UPDATE segments SET text = ?, status = 'done', error = NULL, audio = NULL WHERE id = ?");
  const empty = db.prepare("UPDATE segments SET text = '', status = 'empty', error = NULL WHERE id = ?");
  db.transaction(() => batch.forEach((b, i) => (texts[i] ? done.run(texts[i], b.id) : empty.run(b.id))))();
  batch.forEach((b) => queuedAt.delete(b.id));
}

async function work() {
  for (;;) {
    const settings = getSettings();

    // local analysis first: it is fast and decides how pieces are split
    const pending = db.prepare("SELECT id, meeting_id, start_ms, end_ms, audio FROM segments WHERE status = 'pending' ORDER BY id LIMIT 1").get();
    if (pending) {
      try {
        await analysePiece(pending, settings);
      } catch (e) {
        console.error("[meeting] speaker analysis failed:", e.message);
        workerState.lastError = `Speaker model: ${e.message}`;
        workerState.lastErrorAt = now();
        // still transcribe it, just without a speaker
        db.prepare("UPDATE segments SET status = 'queued' WHERE id = ?").run(pending.id);
        queuedAt.set(pending.id, Date.now());
      }
      continue;
    }

    // transcription, batched per meeting
    const queued = db
      .prepare("SELECT id, meeting_id, start_ms, end_ms, audio FROM segments WHERE status = 'queued' ORDER BY meeting_id, start_ms")
      .all();
    if (!queued.length) break;
    if (!hasKey()) {
      db.prepare("UPDATE segments SET status = 'error', error = 'GEMINI_API_KEY missing' WHERE status = 'queued'").run();
      break;
    }
    const meetingId = queued[0].meeting_id;
    const mine = queued.filter((q) => q.meeting_id === meetingId);
    const ended = !!db.prepare("SELECT ended_at FROM meetings WHERE id = ?").get(meetingId)?.ended_at;
    const audioSecs = mine.reduce((a, q) => a + pcmSeconds(asBuffer(q.audio) || Buffer.alloc(0)), 0);
    const oldest = Math.min(...mine.map((q) => queuedAt.get(q.id) ?? 0));
    const waited = Date.now() - oldest;
    if (!ended && audioSecs < BATCH_AUDIO_SECONDS && mine.length < BATCH_MAX_CLIPS && waited < BATCH_MAX_WAIT_MS) {
      kick(BATCH_MAX_WAIT_MS - waited + 50); // wait a little for more speech, then send
      return;
    }
    // keep requests a reasonable size
    const batch = [];
    let secs = 0;
    for (const q of mine) {
      const d = pcmSeconds(asBuffer(q.audio) || Buffer.alloc(0));
      if (batch.length && (secs + d > 60 || batch.length >= BATCH_MAX_CLIPS)) break;
      batch.push(q);
      secs += d;
    }
    try {
      await transcribeBatch(batch, settings);
      workerState.lastError = null;
    } catch (e) {
      console.error("[meeting] transcription failed:", e.message);
      workerState.lastError = `Transcription: ${e.message}`;
      workerState.lastErrorAt = now();
      const upd = db.prepare("UPDATE segments SET status = 'error', error = ? WHERE id = ?");
      db.transaction(() => batch.forEach((b) => upd.run(String(e.message).slice(0, 300), b.id)))();
      batch.forEach((b) => queuedAt.delete(b.id));
    }
  }

  // nothing left to do: refine meetings that have ended
  const toRefine = db
    .prepare(
      `SELECT id FROM meetings m WHERE ended_at IS NOT NULL AND refined = 0
       AND NOT EXISTS (SELECT 1 FROM segments s WHERE s.meeting_id = m.id AND s.status IN ('pending','queued','analysing','live'))`
    )
    .all();
  for (const m of toRefine) {
    try {
      refineMeeting(m.id);
    } catch (e) {
      console.error("[meeting] refinement failed:", e.message);
    }
    db.prepare("UPDATE meetings SET refined = 1 WHERE id = ?").run(m.id);
  }
}

/**
 * After a meeting: look at every line again with the final voiceprint of each speaker.
 * - unnamed speakers that sound like another speaker are merged into them
 * - lines that clearly sound like a different speaker are moved
 * Lines the user moved by hand and speakers the user renamed are left alone.
 */
export function refineMeeting(meetingId) {
  const settings = getSettings();
  const segs = db
    .prepare("SELECT id, speaker_id, embedding, manual FROM segments WHERE meeting_id = ? AND embedding IS NOT NULL AND speaker_id IS NOT NULL")
    .all(meetingId)
    .map((s) => ({ ...s, emb: blobToF32(s.embedding) }));
  if (segs.length < 2) return;

  const centroids = () => {
    const acc = new Map();
    for (const s of segs) {
      let a = acc.get(s.speaker_id);
      if (!a) acc.set(s.speaker_id, (a = { sum: new Float32Array(s.emb.length), n: 0 }));
      for (let i = 0; i < s.emb.length; i++) a.sum[i] += s.emb[i];
      a.n++;
    }
    return new Map([...acc].map(([id, a]) => [id, { c: normalize(a.sum), n: a.n }]));
  };

  // 1) merge unnamed voices into a very similar voice (one person split in two)
  const mergeAt = settings.voiceClusterThreshold + 0.1;
  for (let again = true; again; ) {
    again = false;
    const cs = centroids();
    const rows = new Map(
      db.prepare("SELECT * FROM meeting_speakers WHERE meeting_id = ? AND merged_into IS NULL").all(meetingId).map((r) => [r.id, r])
    );
    let bestPair = null;
    for (const [a, ca] of cs) {
      const ra = rows.get(a);
      if (!ra || ra.profile_id || ra.renamed) continue; // only automatic "Speaker N" labels
      for (const [b, cb] of cs) {
        if (a === b || !rows.get(b)) continue;
        const sc = cosine(ca.c, cb.c);
        if (sc >= mergeAt && (!bestPair || sc > bestPair.sc)) bestPair = { from: a, into: b, sc };
      }
    }
    if (bestPair) {
      mergeSpeakers(meetingId, bestPair.from, bestPair.into);
      for (const s of segs) if (s.speaker_id === bestPair.from) s.speaker_id = bestPair.into;
      again = true;
    }
  }

  // 2) move lines that clearly fit another speaker better
  const cs = centroids();
  const move = db.prepare("UPDATE segments SET speaker_id = ?, speaker_score = ?, speaker_uncertain = ? WHERE id = ?");
  for (const s of segs) {
    if (s.manual) continue;
    const own = cs.get(s.speaker_id);
    // leave single-line speakers alone: their centroid is the line itself
    if (!own || own.n < 2) continue;
    const ownScore = cosine(s.emb, own.c);
    let best = { id: s.speaker_id, sc: ownScore };
    for (const [id, c] of cs) {
      if (id === s.speaker_id || c.n < 2) continue;
      const sc = cosine(s.emb, c.c);
      if (sc > best.sc) best = { id, sc };
    }
    if (best.id !== s.speaker_id && best.sc >= settings.voiceClusterThreshold && best.sc - ownScore >= 0.1) {
      move.run(best.id, best.sc, best.sc < settings.voiceClusterThreshold + UNSURE_BAND ? 1 : 0, s.id);
      s.speaker_id = best.id;
    }
  }

  // 3) recount lines per speaker
  db.prepare(
    `UPDATE meeting_speakers SET n = (SELECT COUNT(*) FROM segments s WHERE s.speaker_id = meeting_speakers.id)
     WHERE meeting_id = ? AND merged_into IS NULL`
  ).run(meetingId);
}

/** Put failed or empty lines back in the queue (their audio is kept until they succeed). */
export function retryFailed(meetingId) {
  const ids = db
    .prepare("SELECT id FROM segments WHERE meeting_id = ? AND status IN ('error','empty') AND audio IS NOT NULL")
    .all(meetingId)
    .map((r) => r.id);
  if (!ids.length) return 0;
  db.prepare(
    `UPDATE segments SET status = CASE WHEN speaker_id IS NULL AND embedding IS NULL THEN 'pending' ELSE 'queued' END, error = NULL
     WHERE id IN (${ids.map(() => "?").join(",")})`
  ).run(...ids);
  for (const id of ids) queuedAt.set(id, 0); // send right away
  kick();
  return ids.length;
}

// resume anything left unfinished by a previous run
export function resumePending() {
  // turns that were with the browser when the server stopped go to the standard transcription
  db.prepare("UPDATE segments SET status = 'pending' WHERE status = 'analysing'").run();
  db.prepare("UPDATE segments SET status = 'queued' WHERE status = 'live'").run();
  if (db.prepare("SELECT 1 FROM segments WHERE status IN ('pending','queued') LIMIT 1").get()) kick();
}

const tokens = (s) =>
  String(s || "")
    .toLowerCase()

// crude stemming so "works"/"working"/"worked" meet "work" in keyword mode
function stem(w) {
  if (w.length > 5 && w.endsWith("ies")) return w.slice(0, -3) + "y";
  if (w.length > 5 && w.endsWith("ing")) return w.slice(0, -3);
  if (w.length > 4 && w.endsWith("ed")) return w.slice(0, -2);
  if (w.length > 3 && w.endsWith("s") && !w.endsWith("ss")) return w.slice(0, -1);
  return w;
}

function lexicalScore(q, d) {
  const qt = new Set(tokens(q));
  const dt = new Set(tokens(d));
  if (!qt.size || !dt.size) return 0;
  let hit = 0;
  for (const t of qt) if (dt.has(t)) hit++;
  return hit / Math.sqrt(qt.size * dt.size);
}

const norm = (s) => String(s).toLowerCase().replace(/[^\p{L}\p{N}]+/gu, " ").trim();

export async function addMemory({ content, category = "other", source = "manual", conversationId = null }) {
  const t = now();
  const emb = await tryEmbed(content);
  // safety net against the extractor storing the same fact twice
  for (const r of db.prepare("SELECT * FROM memories WHERE status = 'active'").all()) {
    const same = norm(r.content) === norm(content) || (emb && r.embedding && cosine(emb, blobToF32(r.embedding)) > 0.97);
    if (same) {
      db.prepare("UPDATE memories SET updated_at = ? WHERE id = ?").run(t, r.id); // re-confirmed
      return getMemory(r.id);
    }
  }
  const info = db
    .prepare(
      `INSERT INTO memories(content, category, status, source, conversation_id, embedding, created_at, updated_at)
       VALUES (?, ?, 'active', ?, ?, ?, ?, ?)`
    )
    .run(content.trim(), CATEGORIES.includes(category) ? category : "other", source, conversationId, f32ToBlob(emb), t, t);
  return getMemory(info.lastInsertRowid);
}

/** Direct edit from the Memory page. */
export async function editMemory(id, { content, category, status }) {
  const cur = db.prepare("SELECT * FROM memories WHERE id = ?").get(id);
  if (!cur) return null;
  const newContent = content != null ? String(content).trim() : cur.content;
  const emb = newContent !== cur.content ? await tryEmbed(newContent) : blobToF32(cur.embedding);
  db.prepare(
    `UPDATE memories SET content = ?, category = ?, status = ?, embedding = ?, updated_at = ?,
       superseded_by = CASE WHEN ? = 'active' THEN NULL ELSE superseded_by END
     WHERE id = ?`
  ).run(
    newContent,
    category && CATEGORIES.includes(category) ? category : cur.category,
    status && ["active", "superseded", "outdated"].includes(status) ? status : cur.status,
    f32ToBlob(emb),
    now(),
    status || cur.status,
    id
  );
  return getMemory(id);
}

/** Replace an outdated fact with a new one, keeping the old one as history. */
async function supersede(oldId, content, category, conversationId) {
  const old = db.prepare("SELECT * FROM memories WHERE id = ? AND status = 'active'").get(oldId);
  if (!old) return addMemory({ content, category, source: "conversation", conversationId });
  const created = await addMemory({ content, category: category || old.category, source: "conversation", conversationId });
  if (created.id === oldId) return created; // same fact restated: nothing to replace
  db.prepare("UPDATE memories SET status = 'superseded', superseded_by = ?, updated_at = ? WHERE id = ?").run(
    created.id,
    now(),
    oldId
  );
  return created;
}

/**
 * Semantic search over active memories. Falls back to keyword overlap when the
 * local embedding model is unavailable.
 */
export async function searchMemories(query, k = 6, { includeInactive = false } = {}) {
  const rows = db
    .prepare(`SELECT * FROM memories ${includeInactive ? "" : "WHERE status = 'active'"}`)
    .all();
  if (!rows.length || !String(query || "").trim()) return [];
  const qv = await tryEmbed(query);
  const scored = [];
  for (const r of rows) {
    let ev = blobToF32(r.embedding);
    if (qv && !ev) {
      // backfill rows saved while the model was unavailable
      ev = await tryEmbed(r.content);
      if (ev) db.prepare("UPDATE memories SET embedding = ? WHERE id = ?").run(f32ToBlob(ev), r.id);
    }
    const sem = qv && ev ? cosine(qv, ev) : 0;
    const lex = lexicalScore(query, r.content);
    const score = qv && ev ? 0.85 * sem + 0.15 * lex : lex;
    scored.push({ ...rowOut(r), score });
  }
  const minScore = qv ? 0.25 : 0.1;
  return scored
    .filter((s) => s.score >= minScore)
    .sort((a, b) => b.score - a.score)
    .slice(0, k);
}

const EXTRACT_SYSTEM = `You maintain the long-term memory of AURA, a personal assistant, about its single user.
You receive the latest part of a conversation and the existing memories that may be related.
Decide which durable facts to store so AURA can use them in future conversations.

Store only things the USER said or confirmed about themselves or their world:
preferences, personal details, people in their life, work and projects, plans with dates, routines.
Do NOT store: small talk, questions the user asked, general knowledge, the assistant's own suggestions,
one-off requests, or anything the user did not actually say.

Write each memory as one short self-contained sentence in the third person, e.g. "The user's sister is named Priya."
For time-bound facts include the date context (today's date is given).

Operations:
- "add": a new fact that is not already stored.
- "update": an existing memory (memory_id) has changed; content is the full new fact. The old one is kept as history.
- "retire": an existing memory (memory_id) is no longer true and there is no replacement.
- "forget": the user explicitly asked AURA to forget an existing memory (memory_id).
If the fact is already stored with the same meaning, do nothing. Return an empty list when nothing is worth storing.`;

const EXTRACT_SCHEMA = {
  type: "object",
  properties: {
    operations: {
      type: "array",
      items: {
        type: "object",
        properties: {
          action: { type: "string", enum: ["add", "update", "retire", "forget"] },
          memory_id: { type: "integer" },
          content: { type: "string" },
          category: { type: "string", enum: CATEGORIES },
        },
        required: ["action"],
      },
    },
  },
  required: ["operations"],
};

export async function extractFromConversation(conversationId) {
  const conv = db.prepare("SELECT * FROM conversations WHERE id = ?").get(conversationId);
  if (!conv) return [];
  const fresh = db
    .prepare("SELECT * FROM messages WHERE conversation_id = ? AND id > ? ORDER BY id")
    .all(conversationId, conv.extracted_upto);
  if (!fresh.some((m) => m.role === "user")) return [];
  const lastId = fresh[fresh.length - 1].id;
  const before = db
    .prepare("SELECT * FROM messages WHERE conversation_id = ? AND id <= ? ORDER BY id DESC LIMIT 6")
    .all(conversationId, conv.extracted_upto)
    .reverse();

  const userText = fresh.filter((m) => m.role === "user").map((m) => m.text).join("\n");
  const related = await searchMemories(userText, 12);
  const recent = coreMemories(8);
  const candidates = [...new Map([...related, ...recent].map((m) => [m.id, m])).values()];

  const fmt = (m) => `${m.role === "user" ? "User" : "AURA"}: ${m.text}`;
  const prompt = [
    `Today's date: ${new Date().toISOString().slice(0, 10)}`,
    "",
    "Existing related memories:",
    candidates.length ? candidates.map((m) => `[${m.id}] (${m.category}) ${m.content}`).join("\n") : "(none)",
    "",
    before.length ? "Earlier context (already processed):\n" + before.map(fmt).join("\n") + "\n" : "",
    "New messages to process:",
    fresh.map(fmt).join("\n"),
  ].join("\n");

  const out = await generateJSON({ system: EXTRACT_SYSTEM, prompt, schema: EXTRACT_SCHEMA });
  const applied = [];
  const known = new Set(candidates.map((c) => c.id));
  const confirm = getSettings().confirmMemoryChanges;
  for (const op of out.operations || []) {
    const content = String(op.content || "").trim();
    try {
      // changes to facts the user already has: ask first
      if (confirm && ["update", "retire", "forget"].includes(op.action) && known.has(op.memory_id)) {
        if (op.action === "update" && !content) continue;
        const p = propose({ action: op.action, memoryId: op.memory_id, content, category: op.category, conversationId });
        if (p) applied.push({ op: "proposed", proposal: p });
        continue;
      }
      if (op.action === "add" && content) {
        applied.push({ op: "add", memory: await addMemory({ content, category: op.category, source: "conversation", conversationId }) });
      } else if (op.action === "update" && content && known.has(op.memory_id)) {
        applied.push({ op: "update", replaced: op.memory_id, memory: await supersede(op.memory_id, content, op.category, conversationId) });
      } else if (op.action === "retire" && known.has(op.memory_id)) {
        db.prepare("UPDATE memories SET status = 'outdated', updated_at = ? WHERE id = ? AND status = 'active'").run(now(), op.memory_id);
        applied.push({ op: "retire", id: op.memory_id });
      } else if (op.action === "forget" && known.has(op.memory_id)) {
        deleteMemory(op.memory_id);
        applied.push({ op: "forget", id: op.memory_id });
      }
    } catch (e) {
      console.error("[memory] failed to apply", op, e.message);
    }
  }
  db.prepare("UPDATE conversations SET extracted_upto = ? WHERE id = ?").run(lastId, conversationId);
  if (applied.length) console.log(`[memory] conversation ${conversationId}:`, applied.map((a) => a.op).join(", "));
  return applied;
}

const proposalOut = (r) => ({
  id: r.id,
  action: r.action,
  memoryId: r.memory_id,
  content: r.content,
  category: r.category,
  conversationId: r.conversation_id,
  status: r.status,
  createdAt: r.created_at,
  current: getMemory(r.memory_id),
});

function propose({ action, memoryId, content, category, conversationId }) {
  const target = db.prepare("SELECT * FROM memories WHERE id = ? AND status = 'active'").get(memoryId);
  if (!target) return null;
  if (action === "update" && norm(content) === norm(target.content)) return null; // nothing changes
  // don't ask twice for the same change, and don't re-ask one the user turned down
  const same = db
    .prepare("SELECT * FROM memory_proposals WHERE memory_id = ? AND action = ? AND status IN ('pending','rejected')")
    .all(memoryId, action)
    .find((p) => action !== "update" || norm(p.content) === norm(content));
  if (same) return null;
  // a newer proposal for the same memory replaces an older pending one
  db.prepare("DELETE FROM memory_proposals WHERE memory_id = ? AND status = 'pending'").run(memoryId);
  const id = db
    .prepare("INSERT INTO memory_proposals(action, memory_id, content, category, conversation_id, created_at) VALUES (?, ?, ?, ?, ?, ?)")
    .run(action, memoryId, content || null, CATEGORIES.includes(category) ? category : null, conversationId, now()).lastInsertRowid;
  return proposalOut(db.prepare("SELECT * FROM memory_proposals WHERE id = ?").get(id));
}

export function listProposals() {
  return db
    .prepare(
      `SELECT p.* FROM memory_proposals p JOIN memories m ON m.id = p.memory_id
       WHERE p.status = 'pending' AND m.status = 'active' ORDER BY p.created_at`
    )
    .all()
    .map(proposalOut);
}

       WHERE p.status = 'pending' AND m.status = 'active'`

    .get().n;

/** Apply a proposed change. For updates the user may adjust the wording first. */
export async function acceptProposal(id, { content } = {}) {
  const p = db.prepare("SELECT * FROM memory_proposals WHERE id = ? AND status = 'pending'").get(id);
  if (!p) return null;
  let result = null;
  if (p.action === "update") {
    const text = String(content ?? p.content ?? "").trim();
    if (!text) throw Object.assign(new Error("The new memory can't be empty."), { status: 400 });
    result = await supersede(p.memory_id, text, p.category, p.conversation_id);
  } else if (p.action === "retire") {
    db.prepare("UPDATE memories SET status = 'outdated', updated_at = ? WHERE id = ? AND status = 'active'").run(now(), p.memory_id);
  } else if (p.action === "forget") {
    deleteMemory(p.memory_id); // also removes the proposal (cascade)
  }
  db.prepare("UPDATE memory_proposals SET status = 'accepted', decided_at = ? WHERE id = ?").run(now(), id);
  return { ok: true, memory: result };
}

/** Keep the memory as it is. */
export function rejectProposal(id) {
  const n = db.prepare("UPDATE memory_proposals SET status = 'rejected', decided_at = ? WHERE id = ? AND status = 'pending'").run(now(), id).changes;
  // the user just confirmed the current fact
  if (n) db.prepare("UPDATE memories SET updated_at = ? WHERE id = (SELECT memory_id FROM memory_proposals WHERE id = ?)").run(now(), id);
  return n > 0;
}

const timers = new Map();
let chain = Promise.resolve();
export const extractionLog = []; // last few results, shown in the UI

export function scheduleExtraction(conversationId, delayMs = 4000) {
  if (!hasKey() || !getSettings().autoMemory) return;
  clearTimeout(timers.get(conversationId));
  timers.set(
    conversationId,
    setTimeout(() => {
      timers.delete(conversationId);
      chain = chain
        .then(() => extractFromConversation(conversationId))
        .then((applied) => {
          if (applied.length) {
            extractionLog.unshift({ at: now(), conversationId, applied });
            extractionLog.length = Math.min(extractionLog.length, 20);
          }
        })
        .catch((e) => console.error("[memory] extraction failed:", e.message));
    }, delayMs)
  );
}

// Local models run with transformers.js (ONNX Runtime) on this machine.
// Weights are downloaded once from the Hugging Face hub into data/models.
import { MODEL_CACHE_DIR, SEGMENTATION_MODEL, SPEAKER_MODEL, TEXT_EMBED_MODEL } from "./config.mjs";

let tjs = null;
async function lib() {
  if (!tjs) {
    tjs = await import("@huggingface/transformers");
    tjs.env.cacheDir = MODEL_CACHE_DIR;
    tjs.env.allowLocalModels = true;
  }
  return tjs;
}

export const modelStatus = {
  text: { state: "idle", error: null, model: TEXT_EMBED_MODEL },
  speaker: { state: "idle", error: null, model: SPEAKER_MODEL },
  segmentation: { state: "idle", error: null, model: SEGMENTATION_MODEL },
};

function lazy(kind, loader) {
  let p = null;
  let failedAt = 0;
  return () => {
    // after a failure, wait a minute before trying (and logging) again
    if (!p && failedAt && Date.now() - failedAt < 60000) {
      return Promise.reject(new Error(modelStatus[kind].error));
    }
    if (!p) {
      modelStatus[kind].state = "loading";
      p = loader()
        .then((v) => {
          modelStatus[kind].state = "ready";
          return v;
        })
        .catch((e) => {
          modelStatus[kind].state = "error";
          modelStatus[kind].error = String(e?.message || e);
          console.error(`[models] failed to load ${kind} model:`, e?.message || e);
          p = null; // allow a retry later
          failedAt = Date.now();
          throw e;
        });
    }
    return p;
  };
}

const loadText = lazy("text", async () => {
  const { pipeline } = await lib();
  return pipeline("feature-extraction", TEXT_EMBED_MODEL, { dtype: "q8" });
});

const loadSpeaker = lazy("speaker", async () => {
  const { AutoProcessor, AutoModel } = await lib();
  const processor = await AutoProcessor.from_pretrained(SPEAKER_MODEL);
  const model = await AutoModel.from_pretrained(SPEAKER_MODEL, { dtype: "fp32" });
  return { processor, model };
});

const loadSegmentation = lazy("segmentation", async () => {
  const { AutoProcessor, AutoModelForAudioFrameClassification } = await lib();
  const processor = await AutoProcessor.from_pretrained(SEGMENTATION_MODEL);
  const model = await AutoModelForAudioFrameClassification.from_pretrained(SEGMENTATION_MODEL, { dtype: "fp32" });
  return { processor, model };
});

export function normalize(v) {
  let s = 0;
  for (let i = 0; i < v.length; i++) s += v[i] * v[i];
  const n = Math.sqrt(s) || 1;
  const out = new Float32Array(v.length);
  for (let i = 0; i < v.length; i++) out[i] = v[i] / n;
  return out;
}

export function cosine(a, b) {
  if (!a || !b || a.length !== b.length) return 0;
  let dot = 0, na = 0, nb = 0;
  for (let i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    na += a[i] * a[i];
    nb += b[i] * b[i];
  }
  return dot / (Math.sqrt(na) * Math.sqrt(nb) || 1);
}

/** Sentence embedding (384-d, normalised). */
export async function embedText(text) {
  const extractor = await loadText();
  const out = await extractor(text, { pooling: "mean", normalize: true });
  return Float32Array.from(out.data);
}

// serialise audio-model calls; ONNX sessions are not meant to be hammered concurrently
let audioQueue = Promise.resolve();
function serial(run) {
  const p = audioQueue.then(run, run);
  audioQueue = p.catch(() => {});
  return p;
}

const SR = 16000;

async function voiceprint(samples) {
  const { processor, model } = await loadSpeaker();
  const inputs = await processor(samples);
  const out = await model(inputs);
  const t = out.embeddings ?? out.embedding ?? Object.values(out)[0];
  return normalize(t.data);
}

/**
 * Speaker embedding ("voiceprint") for 16 kHz float audio.
 * Up to 20 s is embedded in one pass; longer audio is cut into 10 s windows
 * whose embeddings are averaged.
 */
export function embedSpeaker(samples) {
  return serial(async () => {
    if (samples.length <= 20 * SR) return voiceprint(samples);
    let acc = null;
    for (let start = 0; start + 2 * SR < samples.length; start += 10 * SR) {
      const e = await voiceprint(samples.subarray(start, Math.min(samples.length, start + 10 * SR)));
      if (!acc) acc = new Float32Array(e.length);
      for (let i = 0; i < e.length; i++) acc[i] += e[i];
    }
    return normalize(acc);
  });
}

// pyannote segmentation 3.0 classes ("powerset"): which of up to 3 local speakers are talking
const POWERSET = [[], [0], [1], [2], [0, 1], [0, 2], [1, 2]];

/**
 * Turn the model's frame regions into speaker turns that cover the whole clip.
 * regions: [{ id, start, end }] in seconds (id = powerset class)
 * Returns [{ start, end, local }] where `local` is a speaker index local to this clip.
 * Very short turns are absorbed by their neighbours, and cut points sit in the
 * middle of pauses so no audio is lost.
 */
export function regionsToTurns(regions, duration, minTurn = 0.6) {
  // 1) one label per region: single speakers as-is, overlaps go to whoever was already talking
  const labelled = [];
  let prev = null;
  for (const r of regions) {
    const set = POWERSET[r.id] || [];
    if (!set.length) continue; // silence
    const local = set.length === 1 ? set[0] : set.includes(prev) ? prev : set[0];
    labelled.push({ start: r.start, end: r.end, local });
    prev = local;
  }
  if (!labelled.length) return [{ start: 0, end: duration, local: 0 }];

  // 2) join consecutive regions of the same speaker (across pauses)
  let turns = [];
  for (const r of labelled) {
    const last = turns[turns.length - 1];
    if (last && last.local === r.local) last.end = r.end;
    else turns.push({ ...r });
  }

  // 3) absorb turns that are too short to be a real speaker change
  for (let changed = true; changed && turns.length > 1; ) {
    changed = false;
    let iShort = -1;
    for (let i = 0; i < turns.length; i++) {
      const d = turns[i].end - turns[i].start;
      if (d < minTurn && (iShort < 0 || d < turns[iShort].end - turns[iShort].start)) iShort = i;
    }
    if (iShort >= 0) {
      const t = turns[iShort];
      const before = turns[iShort - 1];
      const after = turns[iShort + 1];
      const into = !after || (before && before.end - before.start >= after.end - after.start) ? before : after;
      into.start = Math.min(into.start, t.start);
      into.end = Math.max(into.end, t.end);
      turns.splice(iShort, 1);
      // neighbours may now be the same speaker
      const merged = [];
      for (const x of turns) {
        const last = merged[merged.length - 1];
        if (last && last.local === x.local) last.end = Math.max(last.end, x.end);
        else merged.push(x);
      }
      turns = merged;
      changed = true;
    }
  }

  // 4) cover the clip: cut in the middle of the gap between turns
  const out = turns.map((t) => ({ ...t }));
  out[0].start = 0;
  out[out.length - 1].end = duration;
  for (let i = 1; i < out.length; i++) {
    const mid = (out[i - 1].end + out[i].start) / 2;
    out[i - 1].end = mid;
    out[i].start = mid;
  }
  return out;
}

/**
 * Detect who speaks when inside one clip of 16 kHz float audio (local speaker
 * indices, not identities). Returns turns covering the whole clip.
 */
export function speakerTurns(samples) {
  return serial(async () => {
    const duration = samples.length / SR;
    const { processor, model } = await loadSegmentation();
    const inputs = await processor(samples);
    const { logits } = await model(inputs);
    const regions = processor.post_process_speaker_diarization(logits, samples.length)[0];
    return regionsToTurns(regions, duration);
  });
}

export function warmUp() {
  loadText().catch(() => {});
  loadSpeaker().catch(() => {});
  loadSegmentation().catch(() => {});
}

test("a speaker change is cut in the middle of the pause", () => {
  const t = regionsToTurns([r(1, 0, 2), r(0, 2, 2.4), r(2, 2.4, 5)], 5);
  assert.equal(t.length, 2);
  assert.deepEqual(t.map((x) => x.local), [0, 1]);
  assert.ok(Math.abs(t[0].end - 2.2) < 1e-9 && t[1].start === t[0].end && t[1].end === 5);
});

test("short blips and overlaps don't create extra turns", () => {
  // 0.2 s of speaker 2 inside speaker 1, then an overlap that continues speaker 1
  const t = regionsToTurns([r(1, 0, 2), r(2, 2, 2.2), r(1, 2.2, 3), r(4, 3, 3.5), r(1, 3.5, 4)], 4);
  assert.deepEqual(t, [{ start: 0, end: 4, local: 0 }]);
});

test("the same speaker coming back keeps the same local index", () => {
  const t = regionsToTurns([r(1, 0, 1.5), r(2, 1.5, 3), r(1, 3, 4.5)], 4.5);
  assert.deepEqual(t.map((x) => x.local), [0, 1, 0]);
});

test("silence only falls back to one turn", () => {
  assert.deepEqual(regionsToTurns([r(0, 0, 3)], 3), [{ start: 0, end: 3, local: 0 }]);
});

import { useCallback, useEffect, useState } from "react";
import "./App.scss";
import { LiveAPIProvider } from "./contexts/LiveAPIContext";
import Sidebar, { View } from "./components/Sidebar";
import AssistantView from "./views/AssistantView";
import MemoryView from "./views/MemoryView";
import MeetingView from "./views/MeetingView";
import SettingsPanel from "./components/SettingsPanel";
import { api, Health } from "./lib/api";

function App() {
  const [view, setView] = useState<View>("assistant");
  const [historyId, setHistoryId] = useState<number | null>(null);
  const [settingsOpen, setSettingsOpen] = useState(false);
  const [health, setHealth] = useState<Health | null>(null);
  const [serverDown, setServerDown] = useState(false);
  const [historyVersion, setHistoryVersion] = useState(0);

  const refreshHealth = useCallback(() => {
    api
      .get<Health>("/api/health")
      .then((h) => {
        setHealth(h);
        setServerDown(false);
      })
      .catch(() => setServerDown(true));
  }, []);

  useEffect(() => {
    refreshHealth();
    const t = setInterval(refreshHealth, 8000);
    return () => clearInterval(t);
  }, [refreshHealth]);

  const openHistory = (id: number | null) => {
    setHistoryId(id);
    setView("assistant");
  };

  return (
    <LiveAPIProvider>
      <div className="app">
        <Sidebar
          view={view}
          onView={(v) => {
            setView(v);
            if (v === "assistant") setHistoryId(null);
          }}
          historyId={historyId}
          onOpenHistory={openHistory}
          historyVersion={historyVersion}
          onOpenSettings={() => setSettingsOpen(true)}
          memoryReviews={health?.memoryReviews ?? 0}
        />
        <main className="main">
          {(serverDown || (health && !health.hasKey)) && (
            <div className="banner banner--warn" role="alert">
              <span className="material-symbols-outlined">warning</span>
              {serverDown ? (
                <span>
                  The AURA server isn't running, so chat, memory and meetings are unavailable. Start everything with{" "}
                  <code>npm run dev</code>.
                </span>
              ) : (
                <span>
                  No Gemini API key found. Add <code>GEMINI_API_KEY=â€¦</code> to the <code>.env</code> file in the project
                  folder and restart the server.
                </span>
              )}
            </div>
          )}
          {view === "assistant" && (
            <AssistantView
              historyId={historyId}
              onCloseHistory={() => setHistoryId(null)}
              onHistoryChanged={() => setHistoryVersion((v) => v + 1)}
              historyVersion={historyVersion}
              memoryReviews={health?.memoryReviews ?? 0}
            />
          )}
          {view === "memory" && <MemoryView onReviewed={refreshHealth} />}
          {/* kept mounted so a meeting keeps recording while you look at other pages */}
          <MeetingView health={health} hidden={view !== "meeting"} />
        </main>
        <SettingsPanel
          open={settingsOpen}
          onClose={() => setSettingsOpen(false)}
          health={health}
          onDataChanged={() => {
            setHistoryVersion((v) => v + 1);
            refreshHealth();
          }}
        />
      </div>
    </LiveAPIProvider>
  );
}

export default App;

import { useEffect, useState } from "react";
import cn from "classnames";

/** Two-step destructive button: first click arms it, second click confirms. */
export default function ConfirmButton({
  onConfirm,
  label,
  confirmLabel = "Confirm",
  icon = "delete",
  small,
  iconOnly,
  disabled,
}: {
  onConfirm: () => void | Promise<void>;
  label: string;
  confirmLabel?: string;
  icon?: string;
  small?: boolean;
  iconOnly?: boolean;
  disabled?: boolean;
}) {
  const [armed, setArmed] = useState(false);
  const [busy, setBusy] = useState(false);
  useEffect(() => {
    if (!armed) return;
    const t = setTimeout(() => setArmed(false), 4000);
    return () => clearTimeout(t);
  }, [armed]);

  return (
    <button
      type="button"
      className={cn(iconOnly && !armed ? "icon-button" : "btn btn--ghost", "btn--danger", { "btn--small": small, "is-armed": armed })}
      disabled={disabled || busy}
      title={armed ? confirmLabel : label}
      aria-label={armed ? confirmLabel : label}
      onClick={async () => {
        if (!armed) return setArmed(true);
        setBusy(true);
        try {
          await onConfirm();
        } finally {
          setBusy(false);
          setArmed(false);
        }
      }}
    >
      <span className="material-symbols-outlined">{icon}</span>
      {(!iconOnly || armed) && <span>{armed ? confirmLabel : label}</span>}
    </button>
  );
}

import { useEffect, useRef, useState } from "react";
import cn from "classnames";
import { api, downloadFile } from "../lib/api";
import ConfirmButton from "./ConfirmButton";

type Conv = { id: number; title: string; pinned: boolean };

/** Editable title plus pin, export and delete for one conversation. */
export function ConversationTitle({ conv, onChanged }: { conv: Conv; onChanged: () => void }) {
  const [editing, setEditing] = useState(false);
  const [value, setValue] = useState(conv.title);
  useEffect(() => setValue(conv.title), [conv.title]);

  const save = async () => {
    setEditing(false);
    const t = value.trim();
    if (t === conv.title) return;
    await api.patch(`/api/conversations/${conv.id}`, { title: t }).catch(() => {});
    onChanged();
  };

  if (editing) {
    return (
      <input
        className="title-input conv-title__input"
        value={value}
        autoFocus
        maxLength={120}
        onChange={(e) => setValue(e.target.value)}
        onBlur={save}
        onKeyDown={(e) => {
          if (e.key === "Enter") e.currentTarget.blur();
          if (e.key === "Escape") {
            setValue(conv.title);
            setEditing(false);
          }
        }}
        aria-label="Conversation name"
      />
    );
  }
  return (
    <h1 className="conv-title">
      <button className="conv-title__btn" onClick={() => setEditing(true)} title="Rename">
        <span className="conv-title__text">{conv.title}</span>
        <span className="material-symbols-outlined conv-title__icon">edit</span>
      </button>
    </h1>
  );
}

export function ConversationActions({
  conv,
  onChanged,
  onDeleted,
  canDelete = true,
}: {
  conv: Conv;
  onChanged: () => void;
  onDeleted?: () => void;
  canDelete?: boolean;
}) {
  const [menu, setMenu] = useState(false);
  const ref = useRef<HTMLDivElement>(null);
  useEffect(() => {
    if (!menu) return;
    const close = (e: MouseEvent) => {
      if (!ref.current?.contains(e.target as Node)) setMenu(false);
    };
    document.addEventListener("mousedown", close);
    return () => document.removeEventListener("mousedown", close);
  }, [menu]);

  const togglePin = async () => {
    await api.patch(`/api/conversations/${conv.id}`, { pinned: !conv.pinned }).catch(() => {});
    onChanged();
  };

  return (
    <div className="conv-actions">
      <button
        className={cn("icon-button", { "is-on": conv.pinned })}
        onClick={togglePin}
        aria-pressed={conv.pinned}
        title={conv.pinned ? "Unpin" : "Pin to the top of the list"}
        aria-label={conv.pinned ? "Unpin conversation" : "Pin conversation"}
      >
        <span className="material-symbols-outlined">keep</span>
      </button>
      <div className="menu-wrap" ref={ref}>
        <button className="icon-button" onClick={() => setMenu((m) => !m)} aria-expanded={menu} aria-haspopup="menu" title="Export" aria-label="Export conversation">
          <span className="material-symbols-outlined">download</span>
        </button>
        {menu && (
          <div className="menu" role="menu">
            {(
              [
                ["md", "Markdown (.md)"],
                ["txt", "Plain text (.txt)"],
                ["json", "JSON (.json)"],
              ] as const
            ).map(([fmt, label]) => (
              <button
                key={fmt}
                role="menuitem"
                onClick={() => {
                  setMenu(false);
                  downloadFile(`/api/conversations/${conv.id}/export?format=${fmt}`, `conversation.${fmt}`).catch((e) => alert(e.message));
                }}
              >
                {label}
              </button>
            ))}
          </div>
        )}
      </div>
      {canDelete && onDeleted && (
        <ConfirmButton
          small
          iconOnly
          onConfirm={async () => {
            await api.del(`/api/conversations/${conv.id}`);
            onDeleted();
          }}
          label="Delete conversation"
          confirmLabel="Delete for good"
        />
      )}
    </div>
  );
}

import { useCallback, useEffect, useState } from "react";
import cn from "classnames";
import { api, MemoryProposal } from "../lib/api";

/**
 * Changes AURA wants to make to memories you already have. Nothing changes until you decide.
 * `signal` is any value that changes when there may be new proposals (e.g. the pending count).
 */
export default function MemoryReview({
  signal,
  compact,
  onChanged,
}: {
  signal?: unknown;
  compact?: boolean;
  onChanged?: () => void;
}) {
  const [items, setItems] = useState<MemoryProposal[]>([]);
  const [editing, setEditing] = useState<Record<number, string>>({});
  const [busy, setBusy] = useState<number | null>(null);
  const [error, setError] = useState<string | null>(null);

  const load = useCallback(() => {
    api
      .get<MemoryProposal[]>("/api/memories/proposals")
      .then(setItems)
      .catch(() => {});
  }, []);
  useEffect(load, [load, signal]);

  const decide = async (p: MemoryProposal, accept: boolean) => {
    setBusy(p.id);
    setError(null);
    try {
      if (accept) await api.post(`/api/memories/proposals/${p.id}/accept`, editing[p.id] != null ? { content: editing[p.id] } : {});
      else await api.post(`/api/memories/proposals/${p.id}/reject`);
      setEditing(({ [p.id]: _, ...rest }) => rest);
      load();
      onChanged?.();
    } catch (e: any) {
      setError(e.message);
    } finally {
      setBusy(null);
    }
  };

  const shown = compact ? items.slice(0, 1) : items;
  if (!items.length) return null;

  return (
    <section className={cn("review", { "review--compact": compact })} aria-label="Memory changes to review">
      {!compact && (
        <h2 className="review__title">
          Needs your OK <span className="review__count">{items.length}</span>
        </h2>
      )}
      {error && <p className="review__error">{error}</p>}
      {shown.map((p) => {
        const old = p.current?.content ?? "";
        const isEditing = editing[p.id] != null;
        return (
          <article key={p.id} className="review__card">
            <span className="material-symbols-outlined review__icon" aria-hidden="true">
              {p.action === "update" ? "published_with_changes" : p.action === "retire" ? "history" : "delete"}
            </span>
            <div className="review__body">
              <p className="review__q">
                {p.action === "update"
                  ? "Update this memory?"
                  : p.action === "retire"
                    ? "Is this no longer true?"
                    : "You asked AURA to forget this. Delete it?"}
                {compact && items.length > 1 && <span className="muted"> ({items.length - 1} more on the Memory page)</span>}
              </p>
              <p className={cn("review__old", { "review__old--struck": p.action === "update" && !isEditing })}>{old}</p>
              {p.action === "update" &&
                (isEditing ? (
                  <textarea
                    className="review__edit"
                    value={editing[p.id]}
                    onChange={(e) => setEditing((x) => ({ ...x, [p.id]: e.target.value }))}
                    rows={2}
                    autoFocus
                    aria-label="New wording"
                  />
                ) : (
                  <p className="review__new">{p.content}</p>
                ))}
              <div className="review__actions">
                <button className="btn btn--primary btn--small" disabled={busy === p.id} onClick={() => decide(p, true)}>
                  {p.action === "update" ? "Update" : p.action === "retire" ? "Mark outdated" : "Delete"}
                </button>
                {p.action === "update" && !isEditing && (
                  <button className="btn btn--ghost btn--small" disabled={busy === p.id} onClick={() => setEditing((x) => ({ ...x, [p.id]: p.content || "" }))}>
                    Edit first
                  </button>
                )}
                <button className="btn btn--ghost btn--small" disabled={busy === p.id} onClick={() => decide(p, false)}>
                  Keep as is
                </button>
              </div>
            </div>
          </article>
        );
      })}
    </section>
  );
}

        )}
        {[
          { label: "Pinned", items: history.filter((c) => c.pinned) },
          { label: "Conversations", items: history.filter((c) => !c.pinned) },
        ]
          .filter((g) => g.items.length)
          .map((g) => (
            <div key={g.label} className="sidebar__group">
              <h2 className="sidebar__heading">{g.label}</h2>
              <ul>
                {g.items.map((c) => (
                  <li key={c.id}>
                    <button
                      className={cn("history-item", {
                        "history-item--active": historyId === c.id,
                        "history-item--live": c.id === conversationId && !historyId,
                      })}
                      onClick={() => onOpenHistory(c.id === conversationId ? null : c.id)}
                      title={c.title}
                    >
                      <span className="history-item__title">{c.title}</span>
                      <span className="history-item__meta">{c.id === conversationId ? "Current" : relativeTime(c.updatedAt)}</span>
                    </button>
                  </li>
                ))}
              </ul>
            </div>
          ))}
      </div>

      <div className="sidebar__footer">
        <div className={cn("status-pill", `status-pill--${status}`, { "status-pill--mic": micOn })} aria-live="polite">
          <span className="status-pill__dot" />
          {statusLabel}
        </div>
        <button className="icon-button" onClick={onOpenSettings} aria-label="Settings" title="Settings">
          <span className="material-symbols-outlined">settings</span>
        </button>
      </div>
    </aside>
  );
}

const QUOTA_RE = /quota|exceeded|resource.?exhausted|rate.?limit/i;
const SEARCH_OFF_NOTICE =
  "Web search was rejected for this model (its search quota is used up or not available on your plan), so AURA switched it off and reconnected. Voice still works. For search, pick a different Live model in Settings, such as gemini-2.5-flash-native-audio-preview-12-2025, then reload the page.";

type SetupResponse = { model: string; voice: string; systemInstruction: string; memoryCount: number; webSearch: boolean };

type TurnSearch = { sources: WebSource[]; searchQueries: string[]; searchWidget?: string };

function mergeSearch(prev: TurnSearch | null, g: GroundingMetadata): TurnSearch {
  const out: TurnSearch = prev ? { ...prev, sources: prev.sources.slice(), searchQueries: prev.searchQueries.slice() } : { sources: [], searchQueries: [] };
  for (const c of g.groundingChunks || []) {
    const uri = c.web?.uri;
    if (uri && !out.sources.some((s) => s.uri === uri)) out.sources.push({ title: c.web?.title || c.web?.domain || uri, uri });
  }
  for (const q of g.webSearchQueries || []) if (q && !out.searchQueries.includes(q)) out.searchQueries.push(q);
  if (g.searchEntryPoint?.renderedContent) out.searchWidget = g.searchEntryPoint.renderedContent;
  return out;
}

export function useLiveAPI(): UseLiveAPIResults {
  const client = useMemo(() => new GenAILiveClient(), []);
  const audioStreamerRef = useRef<AudioStreamer | null>(null);
  const recorder = useMemo(() => new AudioRecorder(), []);

  const [status, setStatus] = useState<LiveStatus>("disconnected");
  const [error, setError] = useState<string | null>(null);
  const [micOn, setMicOnState] = useState(false);
  const [micVolume, setMicVolume] = useState(0);
  const [outVolume, setOutVolume] = useState(0);
  const [messages, setMessages] = useState<Message[]>([]);
  const [conversationId, setConversationId] = useState<number | null>(null);
  const [memoryCount, setMemoryCount] = useState<number | null>(null);
  const [lastRecall, setLastRecall] = useState<UseLiveAPIResults["lastRecall"]>(null);
  const [canResume, setCanResume] = useState(false);
  const [notice, setNotice] = useState<string | null>(null);
  /** whether the running session was started with Google Search */
  const searchOn = useRef(false);
  /** set once Google rejected search for quota reasons; search stays off until the page is reloaded */
  const searchBlocked = useRef(false);

  const convIdRef = useRef<number | null>(null);
  const userClosing = useRef(false);
  const pendingUser = useRef<Message | null>(null);
  const pendingAssistant = useRef<Message | null>(null);
  const saveChain = useRef<Promise<unknown>>(Promise.resolve());
  // web search results for the assistant turn in progress
  const turnSearch = useRef<TurnSearch | null>(null);

  // ---- audio out -------------------------------------------------------------------------
  useEffect(() => {
    if (!audioStreamerRef.current) {
      audioContext({ id: "audio-out" }).then((ctx) => {
        audioStreamerRef.current = new AudioStreamer(ctx);
        audioStreamerRef.current.addWorklet<any>("vumeter-out", VolMeterWorket, (ev: any) => setOutVolume(ev.data.volume));
      });
    }
  }, []);

  // ---- persistence -------------------------------------------------------------------------
  const ensureConversation = useCallback(async () => {
    if (convIdRef.current) return convIdRef.current;
    const c = await api.post<{ id: number }>("/api/conversations");
    convIdRef.current = c.id;
    setConversationId(c.id);
    return c.id;
  }, []);

  const persist = useCallback(
    (m: Message) => {
      // keep messages in order
      saveChain.current = saveChain.current
        .then(async () => {
          const id = await ensureConversation();
          await api.post(`/api/conversations/${id}/messages`, {
            role: m.role,
            text: m.text,
            modality: m.modality,
            sources: m.sources,
            searchQueries: m.searchQueries,
          });
        })
        .catch((e) => console.warn("could not save message", e));
    },
    [ensureConversation]
  );

  // messagesRef is the source of truth; state is a snapshot for rendering
  const messagesRef = useRef<Message[]>([]);
  const publish = useCallback(() => setMessages(messagesRef.current.slice()), []);

  const upsert = useCallback(
    (m: Message) => {
      messagesRef.current.push(m);
      publish();
    },
    [publish]
  );

  const finalize = useCallback(
    (ref: React.MutableRefObject<Message | null>, suffix = "") => {
      const m = ref.current;
      ref.current = null;
      if (!m) return;
      const text = (m.text + suffix).replace(/\s+/g, " ").trim();
      const list = messagesRef.current;
      const i = list.indexOf(m);
      if (!text) {
        if (i >= 0) list.splice(i, 1);
      } else {
        let done: Message = { ...m, text, pending: false };
        if (m.role === "assistant" && turnSearch.current) {
          done = { ...done, ...turnSearch.current };
          turnSearch.current = null;
        }
        if (i >= 0) list[i] = done;
        else list.push(done);
        persist(done);
      }
      publish();
    },
    [persist, publish]
  );

  const appendTo = useCallback(
    (ref: React.MutableRefObject<Message | null>, role: "user" | "assistant", chunk: string, modality: "voice" | "text") => {
      const list = messagesRef.current;
      const cur = ref.current;
      if (cur) {
        const next: Message = { ...cur, text: cur.text + chunk };
        const i = list.indexOf(cur);
        if (i >= 0) list[i] = next;
        else list.push(next);
        ref.current = next;
      } else {
        const m: Message = {
          role,
          text: chunk,
          modality,
          pending: true,
          createdAt: Date.now(),
          ...(role === "assistant" && turnSearch.current ? turnSearch.current : {}),
        };
        list.push(m);
        ref.current = m;
      }
      publish();
    },
    [publish]
  );

  // ---- client events -------------------------------------------------------------------------
  useEffect(() => {
    const onOpen = () => setStatus("connected");
    const onClose = (e: CloseEvent) => {
      const mic = recorder.recording;
      setStatus("disconnected");
      setMicOnState(false);
      finalize(pendingUser);
      finalize(pendingAssistant);
      if (!userClosing.current && searchOn.current && !searchBlocked.current && QUOTA_RE.test(e?.reason || "")) {
        // Google refused search (e.g. no free-tier search quota for this model): carry on without it
        searchBlocked.current = true;
        searchOn.current = false;
        setNotice(SEARCH_OFF_NOTICE);
        const handle = Boolean(client.resumptionHandle);
        setTimeout(() => connectRef.current?.({ resume: handle, withMic: mic }), 0);
        return;
      }
      if (!userClosing.current) {
        const reason = e?.reason ? `: ${e.reason}` : "";
        setError(`The voice session ended unexpectedly${reason}.`);
        setCanResume(Boolean(client.resumptionHandle));
      }
      userClosing.current = false;
      if (convIdRef.current) api.post(`/api/conversations/${convIdRef.current}/end`).catch(() => {});
    };
    const onError = (msg: string) => setError(msg);
    const onInterrupted = () => {
      audioStreamerRef.current?.stop();
      finalize(pendingAssistant, " â€¦");
    };
    const onAudio = (data: ArrayBuffer) => audioStreamerRef.current?.addPCM16(new Uint8Array(data));
    const onInput = (t: string) => appendTo(pendingUser, "user", t, "voice");
    const onOutput = (t: string) => {
      if (pendingUser.current) finalize(pendingUser);
      appendTo(pendingAssistant, "assistant", t, "voice");
    };
    const onTurnComplete = () => {
      finalize(pendingUser);
      finalize(pendingAssistant);
      turnSearch.current = null;
    };
    const onGrounding = (g: GroundingMetadata) => {
      turnSearch.current = mergeSearch(turnSearch.current, g);
      // show the sources on the answer while it is still streaming
      const cur = pendingAssistant.current;
      if (cur) {
        const next: Message = { ...cur, ...turnSearch.current };
        const list = messagesRef.current;
        const i = list.indexOf(cur);
        if (i >= 0) list[i] = next;
        pendingAssistant.current = next;
        publish();
      }
    };
    const onToolCall = async (tc: LiveServerToolCall) => {
      const responses = await Promise.all(
        (tc.functionCalls || []).map(async (fc) => {
          if (fc.name !== "recall_memories") {
            return { id: fc.id, name: fc.name, response: { error: "unknown function" } };
          }
          const query = String((fc.args as any)?.query || "");
          try {
            const results = await api.get<Memory[]>(`/api/memories/search?q=${encodeURIComponent(query)}&k=6`);
            setLastRecall({ query, results });
            return {
              id: fc.id,
              name: fc.name,
              response: {
                memories: results.map((r) => ({
                  fact: r.content,
                  lastConfirmed: new Date(r.updatedAt).toISOString().slice(0, 10),
                })),
              },
            };
          } catch (e: any) {
            return { id: fc.id, name: fc.name, response: { error: e.message } };
          }
        })
      );
      client.sendToolResponse({ functionResponses: responses });
    };
    const onGoAway = () => {
      // server is about to recycle the connection: hop to a fresh one, keeping context
      if (client.resumptionHandle) {
        userClosing.current = true;
        const mic = recorder.recording;
        client.disconnect();
        connectRef.current?.({ resume: true, withMic: mic });
      }
    };

    client
      .on("open", onOpen)
      .on("close", onClose)
      .on("error", onError)
      .on("interrupted", onInterrupted)
      .on("audio", onAudio)
      .on("inputtranscription", onInput)
      .on("outputtranscription", onOutput)
      .on("text", onOutput)
      .on("turncomplete", onTurnComplete)
      .on("grounding", onGrounding)
      .on("toolcall", onToolCall)
      .on("goaway", onGoAway);
    return () => {
      client.removeAllListeners();
      client.disconnect();
    };
  }, [client, recorder, appendTo, finalize, publish]);

  // ---- microphone ------------------------------------------------------------------------------
  useEffect(() => {
    const onData = (b64: string) => client.sendAudio(b64);
    if (status === "connected" && micOn) {
      recorder.on("data", onData).on("volume", setMicVolume);
      recorder.start().catch((e) => {
        setError(e.message);
        setMicOnState(false);
      });
    } else {
      recorder.stop();
    }
    return () => {
      recorder.off("data", onData).off("volume", setMicVolume);
    };
  }, [status, micOn, client, recorder]);

  // ---- actions -------------------------------------------------------------------------------------
  const connect = useCallback(
    async ({ resume = false, withMic = true }: { resume?: boolean; withMic?: boolean } = {}): Promise<boolean> => {
      if (client.status !== "disconnected") return true;
      setError(null);
      setCanResume(false);
      setStatus("connecting");
      try {
        // a continued conversation gives the assistant its earlier messages
        const setup = await api.get<SetupResponse>(
          `/api/live/setup${!resume && convIdRef.current ? `?conversation=${convIdRef.current}` : ""}`
        );
        setMemoryCount(setup.memoryCount);
        const handle = resume ? client.resumptionHandle : null;
        if (!resume) client.resumptionHandle = null;
        const useSearch = setup.webSearch && !searchBlocked.current;
        searchOn.current = useSearch;
        const config: LiveConnectConfig = {
          responseModalities: [Modality.AUDIO],
          speechConfig: { voiceConfig: { prebuiltVoiceConfig: { voiceName: setup.voice } } },
          systemInstruction: { parts: [{ text: setup.systemInstruction }] },
          inputAudioTranscription: {},
          outputAudioTranscription: {},
          tools: useSearch
            ? [{ googleSearch: {} }, { functionDeclarations: [recallDeclaration] }]
            : [{ functionDeclarations: [recallDeclaration] }],
          sessionResumption: handle ? { handle } : {},
          contextWindowCompression: { slidingWindow: {} },
        };
        await client.connect(setup.model, config);
        setStatus("connected");
        if (withMic) setMicOnState(true);
        return true;
      } catch (e: any) {
        setStatus("disconnected");
        if (searchOn.current && !searchBlocked.current && QUOTA_RE.test(String(e?.message || ""))) {
          searchBlocked.current = true;
          searchOn.current = false;
          setNotice(SEARCH_OFF_NOTICE);
          return connectRef.current ? connectRef.current({ resume, withMic }) : false;
        }
        setError(`Couldn't start the voice session. ${e.message}`);
        return false;
      }
    },
    [client]
  );
  const connectRef = useRef(connect);
  connectRef.current = connect;

  const disconnect = useCallback(() => {
    userClosing.current = true;
    setMicOnState(false);
    audioStreamerRef.current?.stop();
    finalize(pendingUser);
    finalize(pendingAssistant);
    if (!client.disconnect()) userClosing.current = false;
    setStatus("disconnected");
    if (convIdRef.current) api.post(`/api/conversations/${convIdRef.current}/end`).catch(() => {});
  }, [client, finalize]);

  const sendText = useCallback(
    async (text: string) => {
      const t = text.trim();
      if (!t) return;
      if (client.status === "disconnected") {
        const ok = await connect({ withMic: false });
        if (!ok) return;
      }
      finalize(pendingUser);
      finalize(pendingAssistant);
      const m: Message = { role: "user", text: t, modality: "text", createdAt: Date.now() };
      upsert(m);
      persist(m);
      const parts: Part[] = [];
      try {
        const hits = (await api.get<Memory[]>(`/api/memories/search?q=${encodeURIComponent(t)}&k=4`)).filter(
          (h) => (h.score ?? 0) >= 0.35
        );
        if (hits.length) {
          parts.push({
            text:
              "[Context from AURA's long-term memory, possibly relevant â€” use only if it helps]\n" +
              hits.map((h) => `- ${h.content}`).join("\n"),
          });
        }
      } catch {}
      parts.push({ text: t });
      client.send(parts, true);
    },
    [client, connect, finalize, persist, upsert]
  );

  const newConversation = useCallback(() => {
    if (client.status !== "disconnected") disconnect();
    client.resumptionHandle = null;
    convIdRef.current = null;
    setConversationId(null);
    messagesRef.current = [];
    publish();
    setCanResume(false);
    setError(null);
    setLastRecall(null);
  }, [client, disconnect, publish]);

  const continueConversation = useCallback(
    async (id: number) => {
      const c = await api.get<{ id: number; messages: Message[] }>(`/api/conversations/${id}`);
      if (client.status !== "disconnected") disconnect();
      client.resumptionHandle = null;
      convIdRef.current = c.id;
      setConversationId(c.id);
      messagesRef.current = c.messages.map((m) => ({ ...m, pending: false }));
      publish();
      setCanResume(false);
      setError(null);
      setLastRecall(null);
    },
    [client, disconnect, publish]
  );

  const setMicOn = useCallback((on: boolean) => setMicOnState(on), []);
  const clearError = useCallback(() => setError(null), []);
  const clearNotice = useCallback(() => setNotice(null), []);

  return {
    status,
    error,
    clearError,
    notice,
    clearNotice,
    canResume,
    connect,
    disconnect,
    micOn,
    setMicOn,
    micVolume,
    outVolume,
    messages,
    conversationId,
    sendText,
    newConversation,
    continueConversation,
    memoryCount,
    lastRecall,
  };
}

// Tiny fetch wrapper for the local AURA server (proxied by the dev server).

async function request<T>(method: string, url: string, body?: unknown, raw?: BodyInit): Promise<T> {
  let res: Response;
  try {
    res = await fetch(url, {
      method,
      headers: raw
        ? { "Content-Type": "application/octet-stream" }
        : body !== undefined
          ? { "Content-Type": "application/json" }
          : undefined,
      body: raw ?? (body !== undefined ? JSON.stringify(body) : undefined),
    });
  } catch {
    throw new Error("Can't reach the AURA server. Start it with `npm run dev` and try again.");
  }
  const text = await res.text();
  let data: any = null;
  try {
    data = text ? JSON.parse(text) : null;
  } catch {
    data = text;
  }
  if (!res.ok) {
    if (res.status === 504 || (res.status === 500 && typeof data === "string" && /proxy/i.test(data))) {
      throw new Error("Can't reach the AURA server. Start it with `npm run dev` and try again.");
    }
    throw new Error((data && data.error) || `Request failed (${res.status})`);
  }
  return data as T;
}

export const api = {
  get: <T>(url: string) => request<T>("GET", url),
  post: <T>(url: string, body?: unknown) => request<T>("POST", url, body ?? {}),
  put: <T>(url: string, body?: unknown) => request<T>("PUT", url, body),
  patch: <T>(url: string, body?: unknown) => request<T>("PATCH", url, body),
  del: <T>(url: string) => request<T>("DELETE", url),
  postAudio: <T>(url: string, pcm: ArrayBuffer) => request<T>("POST", url, undefined, pcm),
};

/**
 * Downloads a file from the AURA server. Plain <a download> links don't work in dev:
 * the React dev server doesn't forward page-style requests to the API, so they get the app's HTML.
 */
export async function downloadFile(url: string, fallbackName = "export") {
  let res: Response;
  try {
    res = await fetch(url, { headers: { Accept: "*/*" } });
  } catch {
    throw new Error("Can't reach the AURA server. Start it with `npm run dev` and try again.");
  }
  if (!res.ok) throw new Error(`Export failed (${res.status})`);
  const cd = res.headers.get("Content-Disposition") || "";
  const star = /filename\*=UTF-8''([^;]+)/i.exec(cd);
  const plain = /filename="([^"]+)"/i.exec(cd);
  const name = star ? decodeURIComponent(star[1]) : plain ? plain[1] : fallbackName;
  const href = URL.createObjectURL(await res.blob());
  const a = document.createElement("a");
  a.href = href;
  a.download = name;
  document.body.appendChild(a);
  a.click();
  a.remove();
  setTimeout(() => URL.revokeObjectURL(href), 10_000);
}

function arrayBufferToBase64(buffer: ArrayBuffer) {
  let binary = "";
  const bytes = new Uint8Array(buffer);
  for (let i = 0; i < bytes.byteLength; i++) {
    binary += String.fromCharCode(bytes[i]);
  }
  return window.btoa(binary);
}

export function micErrorMessage(e: any): string {
  const name = e?.name || "";
  if (name === "NotAllowedError" || name === "SecurityError")
    return "Microphone access was blocked. Allow it in your browser's site settings, then try again.";
  if (name === "NotFoundError" || name === "OverconstrainedError")
    return "No microphone was found. Connect one and try again.";
  if (name === "NotReadableError")
    return "The microphone is in use by another app. Close it and try again.";
  return e?.message || "Could not start the microphone.";
}

/**
 * Events: "data" (base64 PCM16 16 kHz), "pcm" (ArrayBuffer PCM16 16 kHz), "volume" (number)
 */
export class AudioRecorder extends EventEmitter {
  stream: MediaStream | undefined;
  audioContext: AudioContext | undefined;
  source: MediaStreamAudioSourceNode | undefined;
  recording: boolean = false;
  recordingWorklet: AudioWorkletNode | undefined;
  vuWorklet: AudioWorkletNode | undefined;

  private starting: Promise<void> | null = null;

  constructor(public sampleRate = 16000) {
    super();
  }

  async start() {
    if (this.recording) return;
    if (this.starting) return this.starting;
    if (!navigator.mediaDevices || !navigator.mediaDevices.getUserMedia) {
      throw new Error("This browser can't record audio. Use a recent Chrome or Edge on localhost.");
    }

    this.starting = (async () => {
      try {
        this.stream = await navigator.mediaDevices.getUserMedia({
          audio: { echoCancellation: true, noiseSuppression: true, autoGainControl: true },
        });
      } catch (e) {
        throw new Error(micErrorMessage(e));
      }
      this.audioContext = await audioContext({ sampleRate: this.sampleRate });
      if (this.audioContext.state === "suspended") await this.audioContext.resume();
      this.source = this.audioContext.createMediaStreamSource(this.stream);

      const workletName = "audio-recorder-worklet";
      await this.audioContext.audioWorklet.addModule(createWorketFromSrc(workletName, AudioRecordingWorklet));
      this.recordingWorklet = new AudioWorkletNode(this.audioContext, workletName);
      this.recordingWorklet.port.onmessage = (ev: MessageEvent) => {
        const arrayBuffer: ArrayBuffer | undefined = ev.data.data.int16arrayBuffer;
        if (arrayBuffer && this.recording) {
          this.emit("pcm", arrayBuffer);
          if (this.listenerCount("data")) this.emit("data", arrayBufferToBase64(arrayBuffer));
        }
      };
      this.source.connect(this.recordingWorklet);

      const vuWorkletName = "vu-meter";
      await this.audioContext.audioWorklet.addModule(createWorketFromSrc(vuWorkletName, VolMeterWorket));
      this.vuWorklet = new AudioWorkletNode(this.audioContext, vuWorkletName);
      this.vuWorklet.port.onmessage = (ev: MessageEvent) => {
        this.emit("volume", ev.data.volume);
      };
      this.source.connect(this.vuWorklet);
      this.recording = true;
    })();

    try {
      await this.starting;
    } catch (e) {
      this.release();
      throw e;
    } finally {
      this.starting = null;
    }
  }

  private release() {
    this.recording = false;
    try {
      this.source?.disconnect();
      this.recordingWorklet?.disconnect();
      this.vuWorklet?.disconnect();
    } catch {}
    this.stream?.getTracks().forEach((track) => track.stop());
    this.stream = undefined;
    this.source = undefined;
    this.recordingWorklet = undefined;
    this.vuWorklet = undefined;
    // a fresh context per recording keeps worklet registration simple
    this.audioContext?.close().catch(() => {});
    this.audioContext = undefined;
    this.emit("volume", 0);
  }

  stop() {
    // stop may be called before start completes
    if (this.starting) {
      this.starting.then(() => this.release(), () => {});
      return;
    }
    this.release();
  }
}

} from "./audioworklet-registry";

export class AudioStreamer {
  private sampleRate: number = 24000;
  private bufferSize: number = 7680;
  // A queue of audio buffers to be played. Each buffer is a Float32Array.
  private audioQueue: Float32Array[] = [];
  private isPlaying: boolean = false;
  // Indicates if the stream has finished playing, e.g., interrupted.
  private isStreamComplete: boolean = false;
  private checkInterval: number | null = null;
  private scheduledTime: number = 0;
  private initialBufferTime: number = 0.1; //0.1 // 100ms initial buffer
  // Web Audio API nodes. source => gain => destination
  public gainNode: GainNode;
  public source: AudioBufferSourceNode;
  private endOfQueueAudioSource: AudioBufferSourceNode | null = null;

  public onComplete = () => {};

  constructor(public context: AudioContext) {
    this.gainNode = this.context.createGain();
    this.source = this.context.createBufferSource();
    this.gainNode.connect(this.context.destination);
    this.addPCM16 = this.addPCM16.bind(this);
  }

  async addWorklet<T extends (d: any) => void>(
    workletName: string,
    workletSrc: string,
    handler: T
  ): Promise<this> {
    let workletsRecord = registeredWorklets.get(this.context);
    if (workletsRecord && workletsRecord[workletName]) {
      // the worklet already exists on this context
      // add the new handler to it
      workletsRecord[workletName].handlers.push(handler);
      return Promise.resolve(this);
      //throw new Error(`Worklet ${workletName} already exists on context`);
    }

    if (!workletsRecord) {
      registeredWorklets.set(this.context, {});
      workletsRecord = registeredWorklets.get(this.context)!;
    }

    // create new record to fill in as becomes available
    workletsRecord[workletName] = { handlers: [handler] };

    const src = createWorketFromSrc(workletName, workletSrc);
    await this.context.audioWorklet.addModule(src);
    const worklet = new AudioWorkletNode(this.context, workletName);

    //add the node into the map
    workletsRecord[workletName].node = worklet;

    return this;
  }

  /**
   * Converts a Uint8Array of PCM16 audio data into a Float32Array.
   * PCM16 is a common raw audio format, but the Web Audio API generally
   * expects audio data as Float32Arrays with samples normalized between -1.0 and 1.0.
   * This function handles that conversion.
   * @param chunk The Uint8Array containing PCM16 audio data.
   * @returns A Float32Array representing the converted audio data.
   */
  private _processPCM16Chunk(chunk: Uint8Array): Float32Array {
    const float32Array = new Float32Array(chunk.length / 2);
    const dataView = new DataView(chunk.buffer);

    for (let i = 0; i < chunk.length / 2; i++) {
      try {
        const int16 = dataView.getInt16(i * 2, true);
        float32Array[i] = int16 / 32768;
      } catch (e) {
        console.error(e);
      }
    }
    return float32Array;
  }

  addPCM16(chunk: Uint8Array) {
    // Reset the stream complete flag when a new chunk is added.
    this.isStreamComplete = false;
    // Process the chunk into a Float32Array
    let processingBuffer = this._processPCM16Chunk(chunk);
    // Add the processed buffer to the queue if it's larger than the buffer size.
    // This is to ensure that the buffer is not too large.
    while (processingBuffer.length >= this.bufferSize) {
      const buffer = processingBuffer.slice(0, this.bufferSize);
      this.audioQueue.push(buffer);
      processingBuffer = processingBuffer.slice(this.bufferSize);
    }
    // Add the remaining buffer to the queue if it's not empty.
    if (processingBuffer.length > 0) {
      this.audioQueue.push(processingBuffer);
    }
    // Start playing if not already playing.
    if (!this.isPlaying) {
      this.isPlaying = true;
      // Initialize scheduledTime only when we start playing
      this.scheduledTime = this.context.currentTime + this.initialBufferTime;
      this.scheduleNextBuffer();
    }
  }

  private createAudioBuffer(audioData: Float32Array): AudioBuffer {
    const audioBuffer = this.context.createBuffer(
      1,
      audioData.length,
      this.sampleRate
    );
    audioBuffer.getChannelData(0).set(audioData);
    return audioBuffer;
  }

  private scheduleNextBuffer() {
    const SCHEDULE_AHEAD_TIME = 0.2;

    while (
      this.audioQueue.length > 0 &&
      this.scheduledTime < this.context.currentTime + SCHEDULE_AHEAD_TIME
    ) {
      const audioData = this.audioQueue.shift()!;
      const audioBuffer = this.createAudioBuffer(audioData);
      const source = this.context.createBufferSource();

      if (this.audioQueue.length === 0) {
        if (this.endOfQueueAudioSource) {
          this.endOfQueueAudioSource.onended = null;
        }
        this.endOfQueueAudioSource = source;
        source.onended = () => {
          if (
            !this.audioQueue.length &&
            this.endOfQueueAudioSource === source
          ) {
            this.endOfQueueAudioSource = null;
            this.onComplete();
          }
        };
      }

      source.buffer = audioBuffer;
      source.connect(this.gainNode);

      const worklets = registeredWorklets.get(this.context);

      if (worklets) {
        Object.entries(worklets).forEach(([workletName, graph]) => {
          const { node, handlers } = graph;
          if (node) {
            source.connect(node);
            node.port.onmessage = function (ev: MessageEvent) {
              handlers.forEach((handler) => {
                handler.call(node.port, ev);
              });
            };
            node.connect(this.context.destination);
          }
        });
      }
      // Ensure we never schedule in the past
      const startTime = Math.max(this.scheduledTime, this.context.currentTime);
      source.start(startTime);
      this.scheduledTime = startTime + audioBuffer.duration;
    }

    if (this.audioQueue.length === 0) {
      if (this.isStreamComplete) {
        this.isPlaying = false;
        if (this.checkInterval) {
          clearInterval(this.checkInterval);
          this.checkInterval = null;
        }
      } else {
        if (!this.checkInterval) {
          this.checkInterval = window.setInterval(() => {
            if (this.audioQueue.length > 0) {
              this.scheduleNextBuffer();
            }
          }, 100) as unknown as number;
        }
      }
    } else {
      const nextCheckTime =
        (this.scheduledTime - this.context.currentTime) * 1000;
      setTimeout(
        () => this.scheduleNextBuffer(),
        Math.max(0, nextCheckTime - 50)
      );
    }
  }

  stop() {
    this.isPlaying = false;
    this.isStreamComplete = true;
    this.audioQueue = [];
    this.scheduledTime = this.context.currentTime;

    if (this.checkInterval) {
      clearInterval(this.checkInterval);
      this.checkInterval = null;
    }

    this.gainNode.gain.linearRampToValueAtTime(
      0,
      this.context.currentTime + 0.1
    );

    setTimeout(() => {
      this.gainNode.disconnect();
      this.gainNode = this.context.createGain();
      this.gainNode.connect(this.context.destination);
    }, 200);
  }

  async resume() {
    if (this.context.state === "suspended") {
      await this.context.resume();
    }
    this.isStreamComplete = false;
    this.scheduledTime = this.context.currentTime + this.initialBufferTime;
    this.gainNode.gain.setValueAtTime(1, this.context.currentTime);
  }

  complete() {
    this.isStreamComplete = true;
    this.onComplete();
  }
}

export function relativeTime(t: number) {
  const d = Date.now() - t;
  const m = Math.round(d / 60000);
  if (m < 1) return "just now";
  if (m < 60) return `${m} min ago`;
  const h = Math.round(m / 60);
  if (h < 24) return `${h} h ago`;
  const days = Math.round(h / 24);
  if (days < 7) return `${days} d ago`;
  return new Date(t).toLocaleDateString(undefined, { month: "short", day: "numeric" });
}

export function clock(ms: number) {
  const s = Math.max(0, Math.floor(ms / 1000));
  const h = Math.floor(s / 3600);
  const mm = String(Math.floor((s % 3600) / 60)).padStart(2, "0");
  const ss = String(s % 60).padStart(2, "0");
  return h ? `${h}:${mm}:${ss}` : `${mm}:${ss}`;
}

export function dateTime(t: number) {
  return new Date(t).toLocaleString(undefined, { dateStyle: "medium", timeStyle: "short" });
}

export type LiveStatus = "disconnected" | "connecting" | "connected";

export class GenAILiveClient extends EventEmitter<LiveClientEventTypes> {
  private _status: LiveStatus = "disconnected";
  public get status() {
    return this._status;
  }

  private _session: Session | null = null;
  public get session() {
    return this._session;
  }

  /** handle that lets a dropped session continue with its context */
  public resumptionHandle: string | null = null;

  constructor() {
    super();
    this.send = this.send.bind(this);
    this.onopen = this.onopen.bind(this);
    this.onerror = this.onerror.bind(this);
    this.onclose = this.onclose.bind(this);
    this.onmessage = this.onmessage.bind(this);
  }

  async connect(model: string, config: LiveConnectConfig): Promise<boolean> {
    if (this._status !== "disconnected") return false;
    this._status = "connecting";

    const callbacks: LiveCallbacks = {
      onopen: this.onopen,
      onmessage: this.onmessage,
      onerror: this.onerror,
      onclose: this.onclose,
    };

    try {
      const { token } = await api.post<{ token: string }>("/api/live/token");
      const ai = new GoogleGenAI({
        apiKey: token,
        httpOptions: { apiVersion: "v1alpha" },
      });
      this._session = await ai.live.connect({ model, config, callbacks });
    } catch (e: any) {
      this._status = "disconnected";
      this._session = null;
      throw new Error(e?.message || "Could not connect to Gemini Live");
    }
    this._status = "connected";
    return true;
  }

  public disconnect() {
    const s = this._session;
    this._session = null;
    this._status = "disconnected";
    if (!s) return false;
    try {
      s.close();
    } catch {}
    return true;
  }

  protected onopen() {
    this.emit("open");
  }

  protected onerror(e: ErrorEvent) {
    this.emit("error", e?.message || "Connection error");
  }

  protected onclose(e: CloseEvent) {
    this._session = null;
    this._status = "disconnected";
    this.emit("close", e);
  }

  protected async onmessage(message: LiveServerMessage) {
    if (message.setupComplete) {
      this.emit("setupcomplete");
    }
    if (message.sessionResumptionUpdate?.resumable && message.sessionResumptionUpdate.newHandle) {
      this.resumptionHandle = message.sessionResumptionUpdate.newHandle;
    }
    if (message.goAway) {
      this.emit("goaway", message.goAway.timeLeft);
    }
    if (message.toolCall) {
      this.emit("toolcall", message.toolCall);
    }

    const sc = message.serverContent;
    if (!sc) return;

    if (sc.interrupted) {
      this.emit("interrupted");
    }
    if (sc.inputTranscription?.text) {
      this.emit("inputtranscription", sc.inputTranscription.text);
    }
    if (sc.outputTranscription?.text) {
      this.emit("outputtranscription", sc.outputTranscription.text);
    }
    if (sc.groundingMetadata) {
      this.emit("grounding", sc.groundingMetadata);
    }
    const parts: Part[] = sc.modelTurn?.parts || [];
    for (const p of parts) {
      if (p.inlineData?.mimeType?.startsWith("audio/pcm") && p.inlineData.data) {
        this.emit("audio", base64ToArrayBuffer(p.inlineData.data));
      } else if (p.text && !p.thought) {
        this.emit("text", p.text);
      }
    }
    if (sc.turnComplete) {
      this.emit("turncomplete");
    }
  }

  /** stream realtime audio (base64 PCM16 @16 kHz) */
  sendAudio(base64: string) {
    this._session?.sendRealtimeInput({
      audio: { mimeType: "audio/pcm;rate=16000", data: base64 },
    });
  }

  sendToolResponse(toolResponse: LiveClientToolResponse) {
    if (toolResponse.functionResponses?.length) {
      this._session?.sendToolResponse({
        functionResponses: toolResponse.functionResponses,
      });
    }
  }

  /** send a typed turn */
  send(parts: Part | Part[], turnComplete: boolean = true) {
    this._session?.sendClientContent({ turns: parts, turnComplete });
  }
}

// Meeting transcription over the Live API with Gemini 3.5 Transcribe Live.
//
// One streaming session is kept open while a meeting records. Each speaker turn
// is sent as its own "activity" (manual voice-activity mode), so every turn gets
// exactly one transcript back. The session is reopened automatically (Live

function toBase64(pcm: Int16Array) {
  const bytes = new Uint8Array(pcm.buffer, pcm.byteOffset, pcm.byteLength);
  let bin = "";
  for (let i = 0; i < bytes.length; i += 0x8000) bin += String.fromCharCode(...bytes.subarray(i, i + 0x8000));
  return btoa(bin);
}

export class LiveTranscriber {
  private session: Session | null = null;
  private connecting: Promise<Session> | null = null;
  private queue: Job[] = [];
  private busy = false;
  private closed = false;
  // transcript of the turn in flight
  private current: { text: string; finished: boolean; touched: number } | null = null;
  private failures = 0;

  constructor(private opts: { vocabulary?: string[]; onStatus?: (s: "connecting" | "ready" | "error", detail?: string) => void } = {}) {}

  /** Transcribe one turn of 16 kHz PCM16 audio. Rejects if the Live service can't be used. */
  transcribe(pcm: Int16Array): Promise<string> {
    if (this.closed) return Promise.reject(new Error("transcriber closed"));
    return new Promise((resolve, reject) => {
      this.queue.push({ pcm, resolve, reject, tries: 0 });
      this.pump();
    });
  }

  close() {
    this.closed = true;
    for (const j of this.queue.splice(0)) j.reject(new Error("transcriber closed"));
    try {
      this.session?.close();
    } catch {}
    this.session = null;
  }

  private async connect(): Promise<Session> {
    if (this.session) return this.session;
    if (this.connecting) return this.connecting;
    this.opts.onStatus?.("connecting");
    this.connecting = (async () => {
      const { token } = await api.post<{ token: string }>("/api/live/token");
      const ai = new GoogleGenAI({ apiKey: token, httpOptions: { apiVersion: "v1alpha" } });
      let opened!: () => void;
      const ready = new Promise<void>((r) => (opened = r));
      const s = await ai.live.connect({
        model: LIVE_TRANSCRIBE_MODEL,
        config: {
          responseModalities: [Modality.TEXT],
          inputAudioTranscription: {
            // empty = automatic language detection, including switching languages mid-sentence
            languageCodes: [],
            ...(this.opts.vocabulary?.length ? { customVocabulary: this.opts.vocabulary.slice(0, 100) } : {}),
          },
          realtimeInputConfig: { automaticActivityDetection: { disabled: true } },
        },
        callbacks: {
          onopen: () => opened(),
          onmessage: (m: LiveServerMessage) => this.onMessage(m),
          onerror: (e: ErrorEvent) => console.warn("[live transcription] error", e?.message),
          onclose: () => {
            if (this.session === s) this.session = null;
          },
        },
      });
      await Promise.race([ready, new Promise((r) => setTimeout(r, 3000))]);
      this.session = s;
      this.opts.onStatus?.("ready");
      return s;
    })();
    try {
      return await this.connecting;
    } finally {
      this.connecting = null;
    }
  }

  private onMessage(m: LiveServerMessage) {
    const sc = m.serverContent;
    if (!sc || !this.current) return;
    const t = sc.inputTranscription;
    if (t?.text) {
      this.current.text += (this.current.text && !/^\s/.test(t.text) ? " " : "") + t.text;
      this.current.touched = Date.now();
    }
    if (t?.finished || sc.turnComplete) {
      this.current.finished = true;
      this.current.touched = Date.now();
    }
  }

  private async pump() {
    if (this.busy || this.closed) return;
    const job = this.queue.shift();
    if (!job) return;
    this.busy = true;
    try {
      const s = await this.connect();
      this.current = { text: "", finished: false, touched: Date.now() };
      s.sendRealtimeInput({ activityStart: {} });
      for (let i = 0; i < job.pcm.length; i += CHUNK) {
        s.sendRealtimeInput({ audio: { mimeType: "audio/pcm;rate=16000", data: toBase64(job.pcm.subarray(i, i + CHUNK)) } });
      }
      s.sendRealtimeInput({ activityEnd: {} });
      const sentAt = Date.now();
      // wait for the final transcript: "finished", or text that stopped changing
      for (;;) {
        await new Promise((r) => setTimeout(r, 150));
        const c = this.current!;
        if (!this.session) throw new Error("Live transcription session closed");
        if (c.finished && Date.now() - c.touched > 150) break;
        if (c.text && Date.now() - c.touched > SETTLE_MS) break;
        if (Date.now() - sentAt > TURN_TIMEOUT_MS) {
          if (c.text) break;
          throw new Error("No transcript from Live transcription");
        }
      }
      const text = this.current!.text.replace(/\s+/g, " ").trim();
      this.current = null;
      this.failures = 0;
      job.resolve(text);
    } catch (e: any) {
      this.current = null;
      this.failures++;
      try {
        this.session?.close();
      } catch {}
      this.session = null;
      if (job.tries < 1 && this.failures < 3) {
        job.tries++;
        this.queue.unshift(job); // try once more on a fresh session
      } else {
        this.opts.onStatus?.("error", e?.message);
        job.reject(e instanceof Error ? e : new Error(String(e)));
      }
    } finally {
      this.busy = false;
      if (this.queue.length) this.pump();
    }
  }
}

const SR = 16000;
function chunk(ms: number, amp: number): ArrayBuffer {
  const n = Math.round((ms / 1000) * SR);
  const a = new Int16Array(n);
  for (let i = 0; i < n; i++) a[i] = Math.round(Math.sin(i / 5) * amp * 32767);
  return a.buffer;
}
function feed(seg: Segmenter, pattern: [number, number][]) {
  for (const [ms, amp] of pattern) for (let t = 0; t < ms; t += 128) seg.push(chunk(Math.min(128, ms - t), amp));
}

// Energy-based voice-activity segmentation of 16 kHz PCM16 audio.
// Cuts the stream into utterances at pauses so each piece can be
// attributed to one speaker and transcribed.

export type SpeechSegment = { startMs: number; endMs: number; pcm: ArrayBuffer };

const SR = 16000;

export class Segmenter {
  private samplesSeen = 0;
  private noiseFloor = 0.004;
  private inSpeech = false;
  private chunks: Int16Array[] = [];
  private segStart = 0;
  private silenceMs = 0;
  private voicedMs = 0;
  private preRoll: Int16Array[] = [];

  constructor(
    private onSegment: (s: SpeechSegment) => void,
    private opts = { pauseMs: 700, maxMs: 10000, minVoicedMs: 400, preRollMs: 300 }
  ) {}

  push(buf: ArrayBuffer) {
    const pcm = new Int16Array(buf);
    if (!pcm.length) return;
    const chunkMs = (pcm.length / SR) * 1000;
    let sum = 0;
    for (let i = 0; i < pcm.length; i++) {
      const v = pcm[i] / 32768;
      sum += v * v;
    }
    const rms = Math.sqrt(sum / pcm.length);
    const threshold = Math.max(0.012, this.noiseFloor * 3);
    const voiced = rms > threshold;
    // track background level slowly while nobody is speaking
    if (!voiced) this.noiseFloor = this.noiseFloor * 0.95 + rms * 0.05;

    const startOfChunk = this.samplesSeen;
    this.samplesSeen += pcm.length;

    if (!this.inSpeech) {
      this.preRoll.push(pcm);
      let preMs = this.preRoll.reduce((a, c) => a + c.length, 0) / SR * 1000;
      while (preMs - (this.preRoll[0].length / SR) * 1000 > this.opts.preRollMs) {
        preMs -= (this.preRoll.shift()!.length / SR) * 1000;
      }
      if (voiced) {
        this.inSpeech = true;
        this.chunks = this.preRoll.slice();
        const preSamples = this.chunks.reduce((a, c) => a + c.length, 0) - pcm.length;
        this.segStart = startOfChunk - preSamples;
        this.preRoll = [];
        this.silenceMs = 0;
        this.voicedMs = chunkMs;
      }
      return;
    }

    this.chunks.push(pcm);
    if (voiced) {
      this.voicedMs += chunkMs;
      this.silenceMs = 0;
    } else {
      this.silenceMs += chunkMs;
    }
    const lenMs = ((this.samplesSeen - this.segStart) / SR) * 1000;
    if (this.silenceMs >= this.opts.pauseMs || lenMs >= this.opts.maxMs) this.cut();
  }

  /** emit whatever is buffered (call when recording stops) */
  flush() {
    if (this.inSpeech) this.cut();
  }

  private cut() {
    // drop most of the trailing silence
    const keepTailMs = Math.min(this.silenceMs, 250);
    const dropSamples = Math.floor(((this.silenceMs - keepTailMs) / 1000) * SR);
    const total = this.chunks.reduce((a, c) => a + c.length, 0);
    const len = Math.max(0, total - dropSamples);
    const out = new Int16Array(len);
    let off = 0;
    for (const c of this.chunks) {
      if (off >= len) break;
      const take = Math.min(c.length, len - off);
      out.set(c.subarray(0, take), off);
      off += take;
    }
    const voicedMs = this.voicedMs;
    const startMs = (this.segStart / SR) * 1000;
    this.inSpeech = false;
    this.chunks = [];
    this.silenceMs = 0;
    this.voicedMs = 0;
    if (voicedMs >= this.opts.minVoicedMs) {
      this.onSegment({ startMs, endMs: startMs + (len / SR) * 1000, pcm: out.buffer });
    }
  }

  get elapsedMs() {
    return (this.samplesSeen / SR) * 1000;
  }
}

export function base64ToArrayBuffer(base64: string) {
  var binaryString = atob(base64);

const AudioRecordingWorklet = `
class AudioProcessingWorklet extends AudioWorkletProcessor {

  // send and clear buffer every 2048 samples, 
  // which at 16khz is about 8 times a second
  buffer = new Int16Array(2048);

  // current write index
  bufferWriteIndex = 0;

  constructor() {
    super();
    this.hasAudio = false;
  }

  /**
   * @param inputs Float32Array[][] [input#][channel#][sample#] so to access first inputs 1st channel inputs[0][0]
   * @param outputs Float32Array[][]
   */
  process(inputs) {
    if (inputs[0].length) {
      const channel0 = inputs[0][0];
      this.processChunk(channel0);
    }
    return true;
  }

  sendAndClearBuffer(){
    this.port.postMessage({
      event: "chunk",
      data: {
        int16arrayBuffer: this.buffer.slice(0, this.bufferWriteIndex).buffer,
      },
    });
    this.bufferWriteIndex = 0;
  }

  processChunk(float32Array) {
    const l = float32Array.length;
    
    for (let i = 0; i < l; i++) {
      // convert float32 -1 to 1 to int16 -32768 to 32767
      const int16Value = float32Array[i] * 32768;
      this.buffer[this.bufferWriteIndex++] = int16Value;
      if(this.bufferWriteIndex >= this.buffer.length) {
        this.sendAndClearBuffer();
      }
    }

    if(this.bufferWriteIndex >= this.buffer.length) {
      this.sendAndClearBuffer();
    }
  }
}
`;

    (id: number, s: { startMs: number; endMs: number; pcm: ArrayBuffer }) => {
      const q = `start=${Math.round(s.startMs)}&end=${Math.round(s.endMs)}`;
      const lt = liveRef.current;
      if (!lt) {
        track(api.postAudio(`/api/meetings/${id}/segments?${q}`, s.pcm).catch((e) => onError(`A piece of audio couldn't be saved: ${e.message}`)));
        return;
      }
      const pcm = new Int16Array(s.pcm);
      track(
        api
          .postAudio<{ turns: { id: number; startMs: number; endMs: number }[] }>(`/api/meetings/${id}/segments?${q}&live=1`, s.pcm)
          .then(({ turns }) =>
            Promise.all(
              turns.map(async (t) => {
                // the server split the piece by speaker: transcribe each turn on its own
                const from = Math.max(0, Math.round(((t.startMs - s.startMs) / 1000) * 16000));
                const to = Math.min(pcm.length, Math.round(((t.endMs - s.startMs) / 1000) * 16000));
                const post = (body: object) => api.post(`/api/meetings/${id}/segments/${t.id}/transcript`, body);
                const current = liveRef.current;
                if (!current) return post({ failed: true });
                try {
                  await post({ text: await current.transcribe(pcm.slice(from, to)) });
                } catch (e: any) {
                  if (liveRef.current) {
                    liveRef.current.close();
                    liveRef.current = null;
                    setTranscriber("standard");
                    onError(`Live transcription stopped working (${e.message}). The rest of this meeting uses standard transcription.`);
                  }
                  await post({ failed: true });
                }
              })
            )
          )
          .catch((e) => onError(`A piece of audio couldn't be saved: ${e.message}`))
      );
    },
    [onError, track]
  );

  const start = useCallback(
    async (id: number) => {
      if (live.status !== "disconnected") live.disconnect(); // one microphone user at a time
      setStarting(true);
      liveRef.current?.close();
      liveRef.current = null;
      try {
        const [settings, profiles] = await Promise.all([api.get<Settings>("/api/settings"), api.get<SpeakerProfile[]>("/api/speakers")]);
        if (settings.meetingTranscriber === "live") {
          // names help the transcriber spell people correctly
          liveRef.current = new LiveTranscriber({ vocabulary: [...new Set(profiles.map((p) => p.name))] });
        }
      } catch {}
      setTranscriber(liveRef.current ? "live" : "standard");
      const r = new AudioRecorder();
      const seg = new Segmenter((s) => upload(id, s));
      r.on("pcm", (buf: ArrayBuffer) => {
        seg.push(buf);
      });
      r.on("volume", (v: number) => setLevel(v));
      try {
        await r.start();
      } catch (e: any) {
        setStarting(false);
        liveRef.current?.close();
        liveRef.current = null;
        await api.del(`/api/meetings/${id}`).catch(() => {}); // nothing was recorded
        throw e;
      }
      recorderRef.current = r;
      segRef.current = seg;
      idRef.current = id;
      setMeetingId(id);
      setElapsed(0);
      setStarting(false);
    },
    [live, upload]
  );

  const stop = useCallback(async () => {
    const id = idRef.current;
    segRef.current?.flush();
    recorderRef.current?.stop();
    recorderRef.current?.removeAllListeners();
    recorderRef.current = null;
    segRef.current = null;
    idRef.current = null;
    setMeetingId(null);
    setLevel(0);
    if (id) await api.patch(`/api/meetings/${id}`, { ended: true }).catch(() => {});
    // let the last turns finish transcribing, then close the Live session
    const lt = liveRef.current;
    if (lt) {
      await Promise.allSettled([...inFlight.current]);
      if (liveRef.current === lt) {
        lt.close();
        liveRef.current = null;
      }
    }
  }, []);

  useEffect(() => setFaviconState({ recording: meetingId != null }), [meetingId]);
  useEffect(() => {
    if (!meetingId) return;
    const t = setInterval(() => setElapsed(segRef.current?.elapsedMs ?? 0), 500);
    return () => clearInterval(t);
  }, [meetingId]);

  // stop cleanly if the page is closed mid-meeting
  useEffect(() => () => {
    recorderRef.current?.stop();
  }, []);

  return { meetingId, recording: meetingId != null, starting, elapsed, level, uploads, transcriber, start, stop };
}

function MeetingDetail({
  id,
  rec,
  onChanged,
  onDeleted,
  onError,
}: {
  id: number;
  rec: Recorder;
  onChanged: () => void;
  onDeleted: () => void;
  onError: (e: string) => void;
}) {
  const [m, setM] = useState<Meeting | null>(null);
  const [title, setTitle] = useState("");
  const recordingThis = rec.meetingId === id;
  const endRef = useRef<HTMLDivElement>(null);

  const load = useCallback(() => {
    api
      .get<Meeting>(`/api/meetings/${id}`)
      .then((x) => {
        setM(x);
        setTitle((t) => t || x.title);
      })
      .catch((e) => onError(e.message));
  }, [id, onError]);

  const pending = m?.segments.filter((s) => BUSY.includes(s.status)).length ?? 0;
  // after recording stops, speakers are re-checked once everything is transcribed
  const refining = !!m && !!m.endedAt && !m.refined && m.segments.length > 0;
  useEffect(() => {
    load();
  }, [load]);
  useEffect(() => {
    if (!recordingThis && !pending && !rec.uploads && !refining) return;
    const t = setInterval(load, 1500);
    return () => clearInterval(t);
  }, [recordingThis, pending, rec.uploads, refining, load]);

  const segCount = m?.segments.length ?? 0;
  useEffect(() => {
    if (recordingThis) endRef.current?.scrollIntoView({ block: "end", behavior: "smooth" });
  }, [segCount, recordingThis]);

  const speakers = useMemo(() => new Map((m?.speakers ?? []).map((s, i) => [s.id, { ...s, hue: SPEAKER_HUES[i % SPEAKER_HUES.length] }])), [m]);

  if (!m) return <div className="meeting__detail" />;

  const failed = m.segments.filter((s) => s.status === "error").length;
  const emptyRetryable = m.segments.filter((s) => s.status === "empty" && s.retryable).length;
  const call = async (p: Promise<unknown>) => {
    try {
      await p;
    } catch (e: any) {
      onError(e.message);
    }
    load();
  };

  return (
    <div className="meeting__detail">
      <div className="meeting__head">
        <input
          className="title-input"
          value={title}
          onChange={(e) => setTitle(e.target.value)}
          onBlur={() => title.trim() && title !== m.title && call(api.patch(`/api/meetings/${id}`, { title })).then(onChanged)}
          aria-label="Meeting title"
        />
        <div className="meeting__actions">
          <button className="btn btn--ghost btn--small" onClick={() => call(downloadFile(`/api/meetings/${id}/export?format=txt`, "meeting.txt"))}>
            <span className="material-symbols-outlined">download</span>Text
          </button>
          <button className="btn btn--ghost btn--small" onClick={() => call(downloadFile(`/api/meetings/${id}/export?format=md`, "meeting.md"))}>
            Markdown
          </button>
          <button className="btn btn--ghost btn--small" onClick={() => call(downloadFile(`/api/meetings/${id}/export?format=json`, "meeting.json"))}>
            JSON
          </button>
          <ConfirmButton small iconOnly disabled={recordingThis} onConfirm={async () => { await api.del(`/api/meetings/${id}`); onDeleted(); }} label="Delete meeting" confirmLabel="Delete meeting" />
        </div>
      </div>
      <p className="view__sub">{dateTime(m.startedAt)}</p>

      {recordingThis && (
        <div className="recbar">
          <Orb size={40} level={rec.level * 8} active tone="recording" />
          <div className="recbar__info">
            <strong>
              Recording {clock(rec.elapsed)}
              <span className="recbar__mode" title={rec.transcriber === "live" ? "Gemini 3.5 Transcribe Live" : "Batched Gemini requests"}>
                {rec.transcriber === "live" ? "Live transcription" : "Standard transcription"}
              </span>
            </strong>
            <span>{pending + rec.uploads > 0 ? `Processing ${pending + rec.uploads} piece${pending + rec.uploads === 1 ? "" : "s"} of speechâ€¦` : "Waiting for speech"}</span>
          </div>
          <button className="btn btn--stop" onClick={() => rec.stop().then(() => { load(); onChanged(); })}>
            <span className="material-symbols-outlined">stop</span>
            Stop recording
          </button>
        </div>
      )}
      {!recordingThis && pending > 0 && <p className="muted">Finishing {pending} remaining piece{pending === 1 ? "" : "s"}â€¦</p>}
      {!recordingThis && !pending && refining && <p className="muted">Re-checking speakers across the whole meetingâ€¦</p>}
      {!failed && emptyRetryable > 0 && !recordingThis && !pending && (
        <div className="banner banner--info">
          <span>
            {emptyRetryable} piece{emptyRetryable === 1 ? "" : "s"} came back without words. If people were talking, try transcribing again.
          </span>
          <button className="btn btn--small" onClick={() => call(api.post(`/api/meetings/${id}/retry`))}>
            Try again
          </button>
        </div>
      )}
      {failed > 0 && (
        <div className="banner banner--error">
          <span>{failed} piece{failed === 1 ? "" : "s"} couldn't be transcribed ({m.segments.find((s) => s.status === "error")?.error}).</span>
          <button className="btn btn--small" onClick={() => call(api.post(`/api/meetings/${id}/retry`))}>
            Retry
          </button>
        </div>
      )}

      {m.speakers.length > 0 && (
        <SpeakerBar speakers={[...speakers.values()]} meetingId={id} onChange={load} onError={onError} />
      )}

      <ol className="transcript">
        {m.segments.length === 0 && <li className="empty">{recordingThis ? "Start talking â€” the first lines appear a few seconds after someone pauses." : "This meeting has no transcript."}</li>}
        {m.segments.map((s) => (
          <TranscriptRow key={s.id} s={s} speakers={speakers} meetingId={id} onChange={load} onError={onError} />
        ))}
      </ol>
      <div ref={endRef} />
    </div>
  );
}

function SpeakerBar({
  speakers,
  meetingId,
  onChange,
  onError,
}: {
  speakers: (MeetingSpeaker & { hue: number })[];
  meetingId: number;
  onChange: () => void;
  onError: (e: string) => void;
}) {
  const [editing, setEditing] = useState<number | null>(null);
  const [value, setValue] = useState("");
  const [mergeFrom, setMergeFrom] = useState<number | null>(null);

  const rename = async (sid: number) => {
    if (value.trim()) await api.patch(`/api/meetings/${meetingId}/speakers/${sid}`, { label: value }).catch((e) => onError(e.message));
    setEditing(null);
    onChange();
  };
  const merge = async (into: number) => {
    if (mergeFrom && into !== mergeFrom) await api.post(`/api/meetings/${meetingId}/speakers/${mergeFrom}/merge`, { into }).catch((e) => onError(e.message));
    setMergeFrom(null);
    onChange();
  };

  return (
    <div className="speakers">
      <span className="speakers__label">{mergeFrom ? "Merge into which speaker?" : "Speakers"}</span>
      {speakers.map((s) =>
        editing === s.id ? (
          <form key={s.id} className="speaker-edit" onSubmit={(e) => { e.preventDefault(); rename(s.id); }}>
            <input autoFocus value={value} onChange={(e) => setValue(e.target.value)} onBlur={() => rename(s.id)} aria-label="Speaker name" />
          </form>
        ) : (
          <span key={s.id} className={cn("speaker-chip", { "is-merge-target": mergeFrom && mergeFrom !== s.id })} style={{ ["--hue" as any]: s.hue }}>
            <button
              className="speaker-chip__name"
              onClick={() => {
                if (mergeFrom) return merge(s.id);
                setEditing(s.id);
                setValue(s.label);
              }}
              title={mergeFrom ? `Merge into ${s.label}` : "Rename everywhere in this meeting"}
            >
              {s.label}
              {s.profileId && (
                <span className="material-symbols-outlined speaker-chip__badge" title={`Matched a voice profile (similarity ${(s.matchScore ?? 0).toFixed(2)})`}>
                  verified
                </span>
              )}
              <span className="speaker-chip__count">{s.segments}</span>
            </button>
            {!mergeFrom && speakers.length > 1 && (
              <button className="speaker-chip__merge" onClick={() => setMergeFrom(s.id)} title={`${s.label} is the same person as someone else`} aria-label={`Merge ${s.label}`}>
                <span className="material-symbols-outlined">call_merge</span>
              </button>
            )}
          </span>
        )
      )}
      {mergeFrom && (
        <button className="btn btn--ghost btn--small" onClick={() => setMergeFrom(null)}>
          Cancel
        </button>
      )}
    </div>
  );
}

function TranscriptRow({
  s,
  speakers,
  meetingId,
  onChange,
  onError,
}: {
  s: Segment;
  speakers: Map<number, MeetingSpeaker & { hue: number }>;
  meetingId: number;
  onChange: () => void;
  onError: (e: string) => void;
}) {
  const [editText, setEditText] = useState<string | null>(null);
  const sp = s.speakerId ? speakers.get(s.speakerId) : undefined;

  const patch = async (body: object) => {
    await api.patch(`/api/meetings/${meetingId}/segments/${s.id}`, body).catch((e) => onError(e.message));
    onChange();
  };

  return (
    <li className={cn("tline", { "tline--pending": BUSY.includes(s.status), "tline--empty": s.status === "empty" })} style={{ ["--hue" as any]: sp?.hue ?? 0 }}>
      <span className="tline__time">{clock(s.startMs)}</span>
      <div className="tline__who">
        <select
          value={s.speakerId ?? ""}
          onChange={(e) => {
            const v = e.target.value;
            if (v === "__new") {
              const name = window.prompt("Name for the new speaker");
              if (name?.trim()) patch({ newLabel: name.trim() });
            } else if (v) patch({ speakerId: Number(v) });
          }}
          aria-label="Speaker for this line"
          className={cn({ unknown: !sp })}
        >
          {!sp && <option value="">{s.status === "pending" ? "Identifyingâ€¦" : "Unknown"}</option>}
          {[...speakers.values()].map((x) => (
            <option key={x.id} value={x.id}>
              {x.label}
            </option>
          ))}
          <option value="__new">New speakerâ€¦</option>
        </select>
        {s.speakerUncertain && (
          <span className="tline__unsure" title="Low confidence: the voice was too short or close to another speaker. Check and correct if needed.">
            unsure
          </span>
        )}
      </div>
      <div className="tline__text">
        {editText != null ? (
          <textarea
            autoFocus
            value={editText}
            onChange={(e) => setEditText(e.target.value)}
            onBlur={() => {
              if (editText !== s.text) patch({ text: editText });
              setEditText(null);
            }}
            rows={2}
          />
        ) : BUSY.includes(s.status) ? (
          <span className="muted">Transcribingâ€¦</span>
        ) : s.status === "error" ? (
          <span className="muted">Not transcribed yet</span>
        ) : s.status === "empty" ? (
          <span className="muted" onDoubleClick={() => setEditText("")} title="Double-click to type what was said">
            No words recognised
          </span>
        ) : (
          <span onDoubleClick={() => setEditText(s.text || "")} title="Double-click to correct the text">
            {s.text}
          </span>
        )}
      </div>
    </li>
  );
}
